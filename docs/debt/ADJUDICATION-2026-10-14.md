# 像素债定性台账（2026-10-14）

## 这是什么

本台账对 2026-10-12 与 2026-10-13 三本 fresh-diff 账本（`docs/debt/FRESH-DIFF-STATIC-2026-10-13.md`、`docs/debt/FRESH-DIFF-2026-10-13.md`、`docs/debt/DE-PARITY-2026-10-13.md`）与登记册 `docs/debt/REGISTRY-2026-10-12.md` 记录的像素债逐面定性，每条归入四类之一：**有意变更 / 合成噪音 / 缺陷候选 / 无证据**。这是对差异的归因登记，**不是像素门通过**——像素门结论只能在缺陷候选逐项复核关闭之后给出。

**采集时点告示**：本地侧截图全部拍自 t110 @ c51cb2d；此后 main 已前进一百多个提交（「一百多提交」是采集时点告示原文的约数，来自本次撰写任务输入，非本台账测量）。本台账中所有「缺陷候选」均为 t110 期状态，按裁定第 12 条**必须在当前线上（与当前 main 本地）复核后才能定为 live bug**。

数字口径：账本数字（差异像素、占比、Δh、mag1、header10、struct10、页高）照抄三本账本 §2/§3/§4 与登记册条目；格内分解数字（族 9 的改名带/缩略图空盒/悬浮圆钮/抽屉图标像素量，Solution 族的位移残差等）照抄本轮定性行的依据列，测量方法见各行 source 列（本轮 ≥10 聚类、本线 PIL 定位、位移复算、裁带目视）。本台账不新造任何数字。登记册条目号（A1/B3…）为本仓库 `REGISTRY-2026-10-12.md` 自己的编号。
