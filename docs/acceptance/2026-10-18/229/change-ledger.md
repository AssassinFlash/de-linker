# #229 德语页头裁定变更台账

授权：2026-10-18 任务中的 Claude 裁定，德语保留与英语相同的导航结构与联系按钮；英语像素不变。

视觉变更只有 `chrome.css` 中的德语桌面规则：六个导航入口左右 padding 由 14px 收回到 5px，
合计让出 `6 × 2 × (14 − 5) = 108px`。文字、字号、44px 高度、图标、LC partial、链接目标、
操作区、联系按钮与 `fit()` 不改。

逐状态验证另修复键盘延迟焦点竞态：菜单关闭后不执行旧的焦点回调；过渡已完成焦点后，兜底定时器不覆盖下一次方向键选择。
这是交互修复，不改变静止画面或菜单内容；两条 DOM 事件回归测试先红后绿。

## 1280 的断点事实

线上英语在 1280 已因现有 `fit()` 的量宽结果折叠，1440/1920 才显示完整桌面导航。
为满足英语 0 像素变更与 EN/DE 同构，1280 保持双方折叠；本票没有把英语 1280 改成桌面整排。
这与 CSS 的 `min-width:1280px` 启用桌面候选布局是两个事实，实际显示以浏览器量宽结果为准。

## 回滚

撤回本票的德语桌面 padding 规则及菜单延迟焦点判断，照既有 present + WindPress 编译管线重新发布；没有数据库或数据迁移。
执行会话只在 c229 应用了该规则，尚未部署。
