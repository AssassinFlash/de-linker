## Contract findings

**Native routing and language ownership match the intended repair.** The three existing shared taxonomies (`product_brand`, `pa_brand`, `pa_series`) are declared through the early Polylang filtered-taxonomy contract. Existing shared term identities are retained; the change creates neither translated term copies nor custom archive URLs. The Woo query hook fills only an absent main-query product type for the whitelist, retaining explicit post types, secondary queries and other taxonomies. The native switcher exception is constrained to the shared public product-taxonomy archive and target-language contract; feed, paged, search, 404 and unrelated requests retain native handling. The rewrite fingerprint includes the shared declarations and changes the cache only when that contract changes.

**Empty loops use the existing LC product templates.** `ArchiveAssignments` derives generic assignment keys from actual registered public/queryable product taxonomies, resolving the existing EN template and its Polylang DE twin. It does not copy HTML, create a new template, override per-term metadata, or silently take an explicit generic owner from another template. Conflict checking precedes writes and scans the template set once instead of producing a many-join metadata query. Drift detection and idempotent synchronization are present. This addresses both truly empty archives and nonempty archives with a no-match search; restricting the assignment to three zero-count shared terms would have missed the latter.

**The producer and rollback retain exact ownership.** A snapshot precedes assignment mutation. Restoration is limited to the saved template IDs and owned generic keys and retains complete metadata value lists, literal backslashes and absence. Writes and restoration have actual readback. Both write and restore paths catch `Throwable`; successful restoration rethrows the original object, while a restoration failure exposes both errors. The existing `present` backup path remains available on failure, with no side-channel backup consumer and no deletion of another template. The previously reproduced write-after-hook Exception/Error partial-write defect is closed in these unchanged source hashes.

**The page changes respect LC/WindPress ownership and EN/DE content.** PHP supplies the neutral or existing filtered empty-result string only. LC markup selects the empty/nonempty surface and uses the native shop URL / label mechanism; WindPress supplies spacing, type, buttons, hover and focus. Existing nonempty count/sort/grid/family rendering is retained. Empty pages retain search, filter state, removable chips and an escape to all products while suppressing a meaningless count/sort strip. No privacy body, product fact, stock, SKU, model, mail recipient or model route is changed. The new neutral copy makes no availability or future-stock promise; the previous filtered-result wording is preserved.
