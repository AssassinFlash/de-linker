Production classification requires a real `TurnError` and `linker_genie_*` code. Those objects all exercise the upstream branch. Replace the fixtures with the actual exported error class/codes; retain success/upstream cases and assert the distinct returned-editor paths. This is part of S1 closure, not evidence that its original exits passed.

The implementation census otherwise captures the relevant producers: independent ordinary field/dictation/file ownership, pending turns, explicit Retry, journal readback/memory fallback, original-owner checkpoints, fresh recovery, both independently built bundles, and marketing adapter alignment. New ordinary records do not fabricate an entry ID. Unknown ownerless v1 has no active production restore/write/delete fallback; actual consumers use the v2 journal. These boundaries are useful and should remain while fixing the findings.

The reviewed EN/DE storage warning states an actual uncertainty rather than promising recovery. English and formal German preserve the same meaning; the reuse of existing Restore/Remove/Choose labels introduces no new marketing claim. The adjacent old specification phrase about discarding the original scope's local record should be aligned with the new bucket contract: quarantine presentation, retain inactive original-owner attempts, and consume only the precise permitted attempt. Historical wording must not override that explicit contract.
