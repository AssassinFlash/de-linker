## 1. How many PV strings can be routed to the 10K0-S2 inputs?

**Status:** pass
**Review:** pass

**EN Q:** How many PV strings can be routed to the 10K0-S2 inputs?

The inverter receives inputs from up to 3 PV strings, grouped into 3 MPPT routes. The datasheet lists 3 MPPT trackers with 1 string per MPPT for the EF HD-P1-10K0-S2.

**DE Q:** Wie viele PV-Strings lassen sich an den 10K0-S2 führen?

Der Wechselrichter nimmt Eingänge von bis zu 3 PV-Strings auf, die in 3 MPPT-Routen gruppiert werden. Das Datenblatt nennt für den EF HD-P1-10K0-S2 3 MPPT-Tracker mit 1 String pro MPPT.
