**EN Q:** Which circuits receive power through the HD-P1-3K68-S2 BACKUP connection?

The BACKUP connection supplies the backup loads. In the 3-inverter cascade diagram the BACKUP output of each EF HD-P1-(3K/3K68/4K6/5K/5K75/6K)-S2 feeds a backup load, while non-controllable loads are shown separately.

**DE Q:** Welche Stromkreise hängen beim HD-P1-3K68-S2 am BACKUP-Anschluss?

Der BACKUP-Anschluss versorgt die Backup-Lasten. Im Kaskadenschaltplan für 3 Wechselrichter speist der BACKUP-Ausgang jedes EF HD-P1-(3K/3K68/4K6/5K/5K75/6K)-S2 eine Backup-Last; nicht steuerbare Lasten sind getrennt dargestellt.

## 2. How many of these inverters can be cascaded?

**Status:** pass
**Review:** pass

**EN Q:** How many of these inverters can be cascaded?

A maximum of three EF HD-P1-(3K/3K68/4K6/5K/5K75/6K)-S2 can be cascaded. In the OCEAN 2 cascade both the primary and the secondary inverter are EF HD-P1-(3K/3K68/4K6/5K/5K75/6K)-S2.

**DE Q:** Wie viele dieser Wechselrichter können kaskadiert werden?

Es können maximal drei EF HD-P1-(3K/3K68/4K6/5K/5K75/6K)-S2 kaskadiert werden. Bei der OCEAN 2 Kaskadierung sind sowohl der primäre als auch der sekundäre Wechselrichter EF HD-P1-(3K/3K68/4K6/5K/5K75/6K)-S2.

**Citation:** OCEAN 2 Single-Phase Installation Guide V1.7 (DE) · p.13 · https://de-linker.com/wp-content/uploads/2026/10/ecoflow-ocean2-single-phase-installation-guide-de-v1-7.pdf
