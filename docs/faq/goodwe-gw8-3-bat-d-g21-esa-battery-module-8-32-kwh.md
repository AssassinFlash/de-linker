## 1. Does GW8.3-BAT-D-G21 include heating?

**Status:** pass
**Review:** pass

**EN Q:** Does GW8.3-BAT-D-G21 include heating?

No. The datasheet lists the GW8.3-BAT-D-G21 with aerosol fire extinguishing (integrated) only; heating is not listed for this model. Heating is optional on the GW8.3-BAT-D-G20.

**DE Q:** Hat GW8.3-BAT-D-G21 eine Heizung?

Nein. Im Datenblatt ist für GW8.3-BAT-D-G21 nur die Aerosol-Brandlöschung (integriert) aufgeführt; eine Heizung ist für dieses Modell nicht genannt. Beim GW8.3-BAT-D-G20 ist die Heizung optional.

**Citation:** GoodWe ESA Series 5–30 kW datasheet (EN) · p.3 · https://de-linker.com/wp-content/uploads/2026/09/GW_ESA-5-30kW_Datasheet-EN.pdf

## 2. How many modules in one column?

**Status:** pass
**Review:** pass

**EN Q:** How many modules in one column?

A single column can stack up to 6 batteries. For single-column stacked installations, the maximum number of parallel units is 6.

**DE Q:** Wie viele Module in einer Säule?

Eine einzelne Säule kann bis zu 6 Batterien aufnehmen. Für gestapelte Installationen in einer Säule beträgt die maximale Anzahl paralleler Einheiten 6.

**Citation:** GoodWe ESA Series 5–30 kW user manual (EN, V1.5) · p.80 · https://de-linker.com/wp-content/uploads/2026/10/GW_ESA-5-30kW_User-Manual-EN_V1.5.pdf
