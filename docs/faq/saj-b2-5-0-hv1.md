## 1. Which inverter does the B2-5.0-HV1 work with?

**Status:** pass
**Review:** pass

**EN Q:** Which inverter does the B2-5.0-HV1 work with?

The B2 battery can only be used as a set with SAJ's H2 high voltage series storage inverter.

**DE Q:** Mit welchem Wechselrichter arbeitet der B2-5.0-HV1?

Der Akku B2 kann nur als Set mit dem H2-Hochspannungsspeicher-Wechselrichter von SAJ verwendet werden.

**EN Q:** How tall and how heavy is the assembled B2-5.0-HV1?

The B2-5.0-HV1 has one module. Its dimensions are 261*626*365 mm (H*W*D) and its weight is 50.5 kg.

Der B2-5.0-HV1 hat ein Modul. Die Abmessungen betragen 261*626*365 mm (H*B*T), das Gewicht beträgt 50,5 kg.

## 3. Where and how is the stack installed?

**Status:** pass
**Review:** pass

**EN Q:** Where and how is the stack installed?

The battery employs either ground mounting or wall mounting, and its position is determined by the drilled holes of the bracket. Mount vertically. Never install the battery tilted forwards, sideways, horizontally or upside down.

**DE Q:** Wo und wie wird der Stapel montiert?

Der Akku wird entweder am Boden oder an der Wand montiert, die Position ergibt sich aus den Bohrlöchern der Halterung. Montieren Sie den Akku vertikal. Installieren Sie den Akku niemals nach vorne, seitlich oder horizontal geneigt oder kopfüber.
