**EN Q:** Which BAT-C cabinet does the Battery Compatibility Overview list for the ETR, and how is GW208.9-BAT-LCD-G10 documented?

The compatibility overview lists the GW208.9-BAT-LCD-G10 battery system for the ETR. It is documented as purchased from GoodWe, and the battery system supports a maximum of 4 clusters in parallel.

**DE Q:** Welchen BAT-C-Schrank listet die Batterie-Kompatibilitätsübersicht für den ETR, und wie ist GW208.9-BAT-LCD-G10 dokumentiert?

Die Kompatibilitätsübersicht listet das Batteriesystem GW208.9-BAT-LCD-G10 für den ETR. Es ist dokumentiert als von GoodWe zu beziehen, und das Batteriesystem unterstützt maximal 4 parallele Cluster.

## 2. Is an external STS needed for the ETR backup path?

**Status:** pass
**Review:** pass

**EN Q:** Is an external STS needed for the ETR backup path?

The inverter can only use the BACK-UP function when paired with STS.

**DE Q:** Ist für den ETR-Notstrompfad ein externer STS nötig?

Der Wechselrichter kann die BACK-UP-Funktion nur in Verbindung mit STS nutzen.

**Citation:** GoodWe ETR 50–125 kW User Manual (EN) · p.57 · https://de-linker.com/wp-content/uploads/2026/10/GW_ETR-50-125kW_User-Manual-EN_V1.0.pdf

## 3. Can PV strings operate in the 1000–1100 V band?

**Status:** pass
**Review:** pass

**EN Q:** Can PV strings operate in the 1000–1100 V band?

For GW80K-ETR-G10/GW99.99K-ETR-G10/GW100K-ETR-G10/GW110K-ETR-G10/GW124.99K-ETR-G10/GW125K-ETR-G10, when the input voltage ranges from 1000V to 1100V, the inverter will enter the standby mode, and the voltage returns to 1000V to enter the normal operation state.

**DE Q:** Können PV-Strings im Bereich von 1000 bis 1100 V betrieben werden?

Für GW80K-ETR-G10/GW99.99K-ETR-G10/GW100K-ETR-G10/GW110K-ETR-G10/GW124.99K-ETR-G10/GW125K-ETR-G10: Wenn die Eingangsspannung zwischen 1000V und 1100V liegt, wechselt der Wechselrichter in den Standby-Modus; bei Rückkehr auf 1000 V wird der Normalbetrieb wieder aufgenommen.

**Citation:** GoodWe ETR Series 80–125 kW Datasheet (EMEA, EN) · p.3 · https://de-linker.com/wp-content/uploads/2026/09/GW_ETR_Datasheet_EMEA-EN_V1.1.pdf
