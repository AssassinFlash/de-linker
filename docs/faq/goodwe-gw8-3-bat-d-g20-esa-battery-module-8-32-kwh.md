## 1. Does GW8.3-BAT-D-G20 include heating?

**Status:** pass
**Review:** pass

**EN Q:** Does GW8.3-BAT-D-G20 include heating?

Heating is optional for the GW8.3-BAT-D-G20. The datasheet lists "Heating (Optional)" for this model. The manual states the battery heating film is optional and the "Battery Heating" function can be enabled only on models configured with the heating film. The battery heating function is unavailable when GW8.3-BAT-D-G20 is mixed with GW5.1-BAT-D-G20, GW5.1-BAT-D-G21, GW8.3-BAT-D-G21, GW6.0-BAT-D-G20 or GW9.0-BAT-D-G20.

**DE Q:** Hat GW8.3-BAT-D-G20 eine Heizung?

Die Heizung ist beim GW8.3-BAT-D-G20 optional. Im Datenblatt ist für dieses Modell "Heating (Optional)" angegeben. Laut Benutzerhandbuch ist die Batterieheizfolie optional, und nur Modelle mit Heizfolie können die Funktion "Batterieheizung" aktivieren. Bei gemischter Verwendung von GW8.3-BAT-D-G20 mit GW5.1-BAT-D-G20, GW5.1-BAT-D-G21, GW8.3-BAT-D-G21, GW6.0-BAT-D-G20 oder GW9.0-BAT-D-G20 ist die Batterieheizungsfunktion nicht verfügbar.

**Citation:** GoodWe ESA Series 5–30 kW datasheet (EN) · p.3 · https://de-linker.com/wp-content/uploads/2026/09/GW_ESA-5-30kW_Datasheet-EN.pdf

## 2. How many modules in one column?

**Status:** pass
**Review:** pass

**EN Q:** How many modules in one column?

A single column can stack up to 6 batteries. For single-column stacked installations, the maximum number of parallel units is 6.

**DE Q:** Wie viele Module in einer Säule?

Eine einzelne Säule kann bis zu 6 Batterien aufnehmen. Für einspaltige gestapelte Installationen beträgt die maximale Anzahl paralleler Einheiten 6.

**Citation:** GoodWe ESA Series 5–30 kW user manual (EN, V1.5) · p.80 · https://de-linker.com/wp-content/uploads/2026/10/GW_ESA-5-30kW_User-Manual-EN_V1.5.pdf
