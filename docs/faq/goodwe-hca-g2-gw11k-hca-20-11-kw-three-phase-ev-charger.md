**EN Q:** Does the 11 kW charger still need an external Type A RCD?

Yes. The datasheet lists under Protection: "External Type A RCD is needed". The technical data table for GW11K-HCA-20 states: "An external Type A residual current device (RCD) is required."

**DE Q:** Braucht das 11-kW-Ladegerät noch einen externen FI Typ A?

Ja. Im Datenblatt steht unter Schutz: „External Type A RCD is needed“. In den technischen Daten für GW11K-HCA-20 steht: „An external Type A residual current device (RCD) is required.“

## 3. Is GW11K-HCA-20 prepared for §14a EnWG?

**Status:** pass
**Review:** pass

**EN Q:** Is GW11K-HCA-20 prepared for §14a EnWG?

The manual describes an EnWG 14a setting: "EnWG 14a: According to the German EnWG (Energy Industry Act) 14a, all SteuVEs (controllable loads) need to be subject to emergency dimming by the grid. The grid operator can temporarily reduce the maximum grid-bought power consumption of controllable loads to 4.2 kW. If only need to use DI4-EnWG 14a, other DI ports no need to wire."

**DE Q:** Ist GW11K-HCA-20 für §14a EnWG vorbereitet?

Das Handbuch beschreibt eine EnWG-14a-Einstellung: „EnWG 14a: According to the German EnWG (Energy Industry Act) 14a, all SteuVEs (controllable loads) need to be subject to emergency dimming by the grid. The grid operator can temporarily reduce the maximum grid-bought power consumption of controllable loads to 4.2 kW. If only need to use DI4-EnWG 14a, other DI ports no need to wire.“
