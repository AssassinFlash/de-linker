## 1. How many OCEAN 2 floor bases does one battery tower use?

**Status:** pass
**Review:** pass

**EN Q:** How many OCEAN 2 floor bases does one battery tower use?

One battery tower uses one battery base. The installation guide lists the battery base as C1 ×1.

**DE Q:** Wie viele OCEAN-2-Bodensockel braucht ein Batterieturm?

Ein Batterieturm verwendet einen Batteriesockel. Die Installationsanleitung führt den Batteriesockel als C1 ×1 auf.

**Citation:** OCEAN 2 three-phase installation guide V1.5 (EN, DE, FR, IT, ES, NL, SV) · p.11 · https://de-linker.com/wp-content/uploads/2026/09/ecoflow-ocean2-p3-s2-installation-guide-v1-5.pdf

## 2. Can this floor base be used for a wall-mounted tower?

**Status:** pass
**Review:** pass

**EN Q:** Can this floor base be used for a wall-mounted tower?

No. For wall-mounted installation, use the EcoFlow Wall-Mounted Battery Base, which is sold separately and supports stacking of up to three batteries. The floor-mounted method is separate.

**DE Q:** Kann dieser Bodensockel für einen Wandturm verwendet werden?

Nein. Für die Wandmontage verwenden Sie den EcoFlow Wand-Batteriesockel, der separat erhältlich ist und das Stapeln von bis zu drei Batterien unterstützt. Die Bodenmontage ist eine separate Methode.

**Citation:** OCEAN 2 three-phase installation guide V1.5 (EN, DE, FR, IT, ES, NL, SV) · p.17 · https://de-linker.com/wp-content/uploads/2026/09/ecoflow-ocean2-p3-s2-installation-guide-v1-5.pdf
