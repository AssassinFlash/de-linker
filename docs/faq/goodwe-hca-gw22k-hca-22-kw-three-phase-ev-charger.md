## 3. Is GW22K-HCA-20 prepared for §14a EnWG?

**Status:** pass
**Review:** pass

**EN Q:** Is GW22K-HCA-20 prepared for §14a EnWG?

Yes. According to the German EnWG 14a, all SteuVEs need to be subject to emergency dimming by the grid. The grid operator can temporarily reduce the maximum grid-bought power consumption of controllable loads to 4.2 kW. If only DI4-EnWG 14a is needed, other DI ports do not need to be wired.

**DE Q:** Ist GW22K-HCA-20 für §14a EnWG vorbereitet?

Ja. Gemäß der deutschen EnWG 14a müssen alle SteuVEs einer Notabschaltung durch das Netz unterliegen. Der Netzbetreiber kann die maximale Netzbezugsleistung steuerbarer Lasten vorübergehend auf 4,2 kW reduzieren. Wenn nur DI4-EnWG 14a benötigt wird, müssen andere DI-Ports nicht verdrahtet werden.
