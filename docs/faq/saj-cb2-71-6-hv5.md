## 1. Which inverters work with the CB2-71.6-HV5?

**Status:** pass
**Review:** pass

**EN Q:** Which inverters work with the CB2-71.6-HV5?

The CB2 battery system can only be used as a set with SAJ's CH2 high voltage series storage inverter. The CB2 battery systems support integration with SAJ CH2 series inverters to work as a commercial & industrial (C&I) energy storage system (ESS).

**DE Q:** Welche Wechselrichter arbeiten mit dem CB2-71.6-HV5?

Das CB2-Batteriesystem kann nur als Set mit dem SAJ CH2 Hochvolt-Speicherwechselrichter verwendet werden. Die CB2-Batteriesysteme unterstützen die Integration mit Wechselrichtern der SAJ CH2-Serie für ein gewerbliches Energiespeichersystem (C&I ESS).

## 2. What are the dimensions and the weight of the cabinet?

**Status:** pass
**Review:** pass

**EN Q:** What are the dimensions and the weight of the cabinet?

The dimensions of the CB2 battery cabinet are 1980 mm (H) x 988 mm (W) x 1065 mm (D). The weight is 1145 kg for the 71.6 kWh model.

**DE Q:** Welche Abmessungen und welches Gewicht hat der Schrank?

Die Abmessungen des CB2-Batterieschranks betragen 1980 mm (H) x 988 mm (B) x 1065 mm (T). Das Gewicht beträgt 1145 kg für das Modell mit 71,6 kWh.

**Citation:** SAJ CHS2 30-50K datasheet with the CB2 battery table, English (covers the CB2-100.3-HV5) · p.2 · https://de-linker.com/wp-content/uploads/2026/10/SAJ_CHS2_30-50K_Datasheet_EN-BEU.pdf

## 3. Can storage be added to an existing CB2 system later?

**Status:** withdrawn
**Review:** withdrawn — The retrieved passages state the maximum of four CB2 battery systems per CH2 inverter, the requirement that all CB2 systems have the same rated energy, and that the multi-cluster procedure is described for a four-cluster system. They do not state whether a CB2 battery system can be added to an existing installation later, so the retrofit question is not answered by these passages.

**EN Q:** Can storage be added to an existing CB2 system later?

The manual does not describe adding a CB2 battery system to an existing installation at a later date. It states that one CH2 inverter can be integrated with four CB2 battery systems at maximum, and that all the CB2 systems are required to have the same rated energy. The connection guideline and procedure for multiple clusters are similar, and the described procedure covers the connection of a four-cluster system.

**DE Q:** Lässt sich ein bestehendes CB2-System später erweitern?

Das Handbuch beschreibt nicht, wie ein CB2-Batteriesystem später zu einer bestehenden Installation hinzugefügt wird. Es gibt an, dass ein CH2-Wechselrichter mit maximal vier CB2-Batteriesystemen integriert werden kann und dass alle CB2-Systeme die gleiche Nennenergie haben müssen. Die Anschlussrichtlinie und das Verfahren für mehrere Cluster sind ähnlich, und das beschriebene Verfahren behandelt den Anschluss eines Systems mit vier Clustern.
