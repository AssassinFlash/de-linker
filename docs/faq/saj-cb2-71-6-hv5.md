## 1. Which inverters work with the CB2-71.6-HV5?

**Status:** pass
**Review:** pass

**EN Q:** Which inverters work with the CB2-71.6-HV5?

The CB2 battery system can only be used as a set with SAJ's CH2 high voltage series storage inverter. The CB2 battery systems support integration with SAJ CH2 series inverters to work as a commercial & industrial (C&I) energy storage system (ESS).

**DE Q:** Welche Wechselrichter arbeiten mit dem CB2-71.6-HV5?

Das CB2-Batteriesystem kann nur als Set mit dem SAJ CH2 Hochvolt-Speicherwechselrichter verwendet werden. Die CB2-Batteriesysteme unterstützen die Integration mit Wechselrichtern der SAJ CH2-Serie für ein gewerbliches Energiespeichersystem (C&I ESS).

**Review:** pass

**EN Q:** What are the dimensions and the weight of the cabinet?

The dimensions of the CB2 battery cabinet are 1980 mm (H) x 988 mm (W) x 1065 mm (D). The weight is 1145 kg for the 71.6 kWh model.

**DE Q:** Welche Abmessungen und welches Gewicht hat der Schrank?

Die Abmessungen des CB2-Batterieschranks betragen 1980 mm (H) x 988 mm (B) x 1065 mm (T). Das Gewicht beträgt 1145 kg für das Modell mit 71,6 kWh.

## 3. Can storage be added to an existing CB2 system later?

**Status:** reject
**Review:** reject — Question asks about adding storage later, but the answer only restates the max four systems and equal rated energy rule; it does not address retrofit/expansion, so it is not an answer to the question asked.

**EN Q:** Can storage be added to an existing CB2 system later?

One CH2 inverter can be integrated with four CB2 battery systems at maximum. All the CB2 systems are required to have the same rated energy.

**DE Q:** Lässt sich ein bestehendes CB2-System später erweitern?

Ein CH2-Wechselrichter kann mit maximal vier CB2-Batteriesystemen integriert werden. Alle CB2-Systeme müssen die gleiche Nennenergie haben.
