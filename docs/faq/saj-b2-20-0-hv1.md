## 1. Which inverter does the B2-20.0-HV1 work with?

**Status:** pass
**Review:** pass

**EN Q:** Which inverter does the B2-20.0-HV1 work with?

The B2 battery can only be used as a set with SAJ's H2 high voltage series storage inverter.

**DE Q:** Mit welchem Wechselrichter arbeitet der B2-20.0-HV1?

Der Akku B2 kann nur als Set mit dem Hochspannungs-Speicherwechselrichter der H2-Serie von SAJ verwendet werden.

## 3. Where and how is the stack installed?

**Status:** pass
**Review:** pass

**EN Q:** Where and how is the stack installed?

The battery employs either ground mounting or wall mounting. Mount vertically; never install the battery tilted forwards, sideways, horizontally or upside down.

**DE Q:** Wo und wie wird der Stapel montiert?

Der Akku wird entweder am Boden oder an der Wand montiert. Vertikal montieren; den Akku niemals nach vorne, seitlich oder horizontal geneigt oder kopfüber installieren.
