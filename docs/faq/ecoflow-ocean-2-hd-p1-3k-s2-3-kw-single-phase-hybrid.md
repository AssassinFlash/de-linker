## 1. Which circuits receive power through the 3K-S2 BACKUP connection?

**Status:** pass
**Review:** pass

**EN Q:** Which circuits receive power through the 3K-S2 BACKUP connection?

The BACKUP connection supplies the backup loads. In the system diagram, the BACKUP output is wired to a distribution box that feeds the backup loads. The diagram also shows non-controllable loads connected on the grid side, not on the BACKUP side.

**DE Q:** Welche Stromkreise hängen beim 3K-S2 am BACKUP-Anschluss?

Der BACKUP-Anschluss versorgt die Backup-Lasten. Im Systemschaltbild ist der BACKUP-Ausgang mit einem Verteilerkasten verbunden, der die Backup-Lasten speist. Das Schaltbild zeigt zudem nicht steuerbare Lasten auf der Netzseite, nicht auf der BACKUP-Seite.

**Citation:** OCEAN 2 Single-Phase Installation Guide V1.7 (DE) · p.14 · https://de-linker.com/wp-content/uploads/2026/10/ecoflow-ocean2-single-phase-installation-guide-de-v1-7.pdf

## 2. How many of these inverters can be cascaded?

**Status:** pass
**Review:** pass

**EN Q:** How many of these inverters can be cascaded?

A maximum of three EF HD-P1-(3K/3K68/4K6/5K/5K75/6K)-S2 inverters can be cascaded.

**DE Q:** Wie viele dieser Wechselrichter können kaskadiert werden?

Es können maximal drei EF HD-P1-(3K/3K68/4K6/5K/5K75/6K)-S2-Wechselrichter kaskadiert werden.

**Citation:** OCEAN 2 Single-Phase Installation Guide V1.7 (DE) · p.13 · https://de-linker.com/wp-content/uploads/2026/10/ecoflow-ocean2-single-phase-installation-guide-de-v1-7.pdf

## 3. Is the IOT dongle required?

**Status:** pass
**Review:** pass

**EN Q:** Is the IOT dongle required?

The EcoFlow IOT Dongle ESS must be configured. The installation guide lists it as "Muss konfiguriert werden" (must be configured).

**DE Q:** Ist der IOT-Dongle Pflicht?

Der EcoFlow IOT Dongle ESS muss konfiguriert werden. Die Installationsanleitung führt ihn als "Muss konfiguriert werden" auf.

**Citation:** OCEAN 2 Single-Phase Installation Guide V1.7 (DE) · p.29 · https://de-linker.com/wp-content/uploads/2026/10/ecoflow-ocean2-single-phase-installation-guide-de-v1-7.pdf
