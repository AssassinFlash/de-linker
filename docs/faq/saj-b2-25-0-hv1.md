**EN Q:** Which inverter does the B2-25.0-HV1 work with?

The B2-25.0-HV1 can only be used as a set with SAJ's H2 high voltage series storage inverter.

## 3. Where and how is the stack installed?

**Status:** pass
**Review:** pass

**EN Q:** Where and how is the stack installed?

The stack is installed either on the ground or on a wall. Mount it vertically; never install it tilted forwards, sideways, horizontally or upside down. For wall mounting, use a solid wall; cavity walls and timber walls are not allowed.

**DE Q:** Wo und wie wird der Stapel montiert?

Der Stapel wird entweder auf dem Boden oder an der Wand montiert. Montieren Sie ihn vertikal; installieren Sie ihn niemals nach vorne, seitlich, horizontal oder kopfüber geneigt. Für die Wandmontage verwenden Sie eine massive Wand; Hohlwände und Holzwände sind nicht zulässig.

**Citation:** SAJ B2 high-voltage battery, B2-5.0 to B2-25.0: user manual V1.2 (English) · p.13 · https://de-linker.com/wp-content/uploads/2026/10/B2-5.0-HV1-HV5-user-manual-EN-EU.pdf
