## 1. Which inverters work with the CB2-85.9-HV5?

**Status:** pass
**Review:** pass

**EN Q:** Which inverters work with the CB2-85.9-HV5?

The CB2 battery system can only be used as a set with SAJ's CH2 high voltage series storage inverter. The CB2 battery systems support integration with SAJ CH2 series inverters to work as a commercial & industrial (C&I) energy storage system (ESS).

**DE Q:** Welche Wechselrichter arbeiten mit dem CB2-85.9-HV5?

Das CB2-Batteriesystem kann nur als Set mit dem SAJ CH2 Hochvolt-Speicherwechselrichter verwendet werden. Die CB2-Batteriesysteme unterstützen die Integration mit Wechselrichtern der SAJ CH2-Serie für den Betrieb als gewerbliches und industrielles (C&I) Energiespeichersystem (ESS).

## 3. Can storage be added to an existing CB2 system later?

**Status:** withdrawn
**Review:** withdrawn — The passages state the maximum of four CB2 battery systems per CH2 inverter, the requirement that all CB2 systems have the same rated energy, and that the CB2 battery system can only be used as a set with SAJ's CH2 high voltage series storage inverter. They do not state whether storage can be added to an existing CB2 system later, so the question cannot be answered from these passages.

**EN Q:** Can storage be added to an existing CB2 system later?

The manual does not state whether storage can be added to an existing CB2 system later. It states that one CH2 inverter can be integrated with four CB2 battery systems at maximum, and that all CB2 systems must have the same rated energy. It also states that the CB2 battery system can only be used as a set with SAJ's CH2 high voltage series storage inverter.

**DE Q:** Lässt sich ein bestehendes CB2-System später erweitern?

Das Handbuch sagt nicht, ob ein bestehendes CB2-System später erweitert werden kann. Es nennt, dass ein CH2-Wechselrichter mit maximal vier CB2-Batteriesystemen integriert werden kann und dass alle CB2-Systeme die gleiche Nennenergie aufweisen müssen. Es nennt außerdem, dass das CB2-Batteriesystem nur als Set mit dem Hochvolt-Speicherwechselrichter der CH2-Serie von SAJ verwendet werden kann.
