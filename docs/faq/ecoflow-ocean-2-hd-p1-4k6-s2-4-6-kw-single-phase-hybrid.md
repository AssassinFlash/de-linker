## 1. Which circuits receive power through the HD-P1-4K6-S2 BACKUP connection?

**Status:** pass
**Review:** pass

**EN Q:** Which circuits receive power through the HD-P1-4K6-S2 BACKUP connection?

The BACKUP connection supplies the backup loads. In the three-inverter cascade diagram, each inverter's BACKUP output feeds a backup load.

**DE Q:** Welche Stromkreise hängen beim HD-P1-4K6-S2 am BACKUP-Anschluss?

Der BACKUP-Anschluss versorgt die Backup-Lasten. Im Kaskadenschaltplan für drei Wechselrichter speist der BACKUP-Ausgang jedes Wechselrichters eine Backup-Last.

**Citation:** OCEAN 2 Single-Phase Installation Guide V1.7 (DE) · p.15 · https://de-linker.com/wp-content/uploads/2026/10/ecoflow-ocean2-single-phase-installation-guide-de-v1-7.pdf

## 2. How many of these inverters can be cascaded?

**Status:** pass
**Review:** pass

**EN Q:** How many of these inverters can be cascaded?

A maximum of three EF HD-P1-(3K/3K68/4K6/5K/5K75/6K)-S2 inverters can be cascaded.

**DE Q:** Wie viele dieser Wechselrichter können kaskadiert werden?

Es können maximal drei EF HD-P1-(3K/3K68/4K6/5K/5K75/6K)-S2-Wechselrichter kaskadiert werden.

**Citation:** OCEAN 2 Single-Phase Installation Guide V1.7 (DE) · p.13 · https://de-linker.com/wp-content/uploads/2026/10/ecoflow-ocean2-single-phase-installation-guide-de-v1-7.pdf

## 3. Is the IOT dongle required?

**Status:** pass
**Review:** pass

**EN Q:** Is the IOT dongle required?

The installation guide lists the EcoFlow IOT-Dongle ESS with the note "Muss konfiguriert werden" (must be configured). The guide's table of contents carries the same entry: "Installation des EcoFlow IOT-Dongle ESS (Muss konfiguriert werden)". The 4G-Dongle ESS (EU) is listed as an option in the same documents.

**DE Q:** Ist der IOT-Dongle Pflicht?

Der Installationsleitfaden führt den EcoFlow IOT-Dongle ESS mit dem Hinweis "Muss konfiguriert werden". Das Inhaltsverzeichnis des Leitfadens enthält denselben Eintrag: "Installation des EcoFlow IOT-Dongle ESS (Muss konfiguriert werden)". Der 4G-Dongle ESS (EU) ist in denselben Dokumenten als Option aufgeführt.

**Citation:** OCEAN 2 Single-Phase Installation Guide V1.7 (DE) · p.29 · https://de-linker.com/wp-content/uploads/2026/10/ecoflow-ocean2-single-phase-installation-guide-de-v1-7.pdf
