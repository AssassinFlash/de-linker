# 已确定的范围与输出合同

日期：2026-10-22。决策责任：Codex；依据用户“全权交给你来负责”的当期委托及本地图初审及后续深入方法、原件和欧洲工程研究。该委托解除指定Claude前置要求，允许本线作产品与技术取舍；它没有把尚未执行的工程、操作或上线验收变成通过。本轮继续审查及设计，不修改业务实现或生产。

对应问题：[欧洲工商业屋顶与系统选型的想法能否可信落地？](https://github.com/AssassinFlash/de-linker/issues/552)。完整问题证据和候选重构结构见[综合方案](README.md)。

## 决定

**采用一个面向全欧洲的统一方案设计工具：屋顶布局、发电、用电与储能、设备配置和报告是同一项目中的工作区。住宅与工商业共用这一工具，安装商、EPC和经销商可处理不同类型的项目。** 用户2026-10-22在理解关系后明确“没必要拆”“没必要硬区分”。产品结构据此确定，具体交互与工程正确性仍须验证。 选择这条路线的依据是：已有服务能独立提供屋面/排布，成熟产品存在尺寸/图纸/自动模式与项目交接，而当前仅传kWp的数据链已产生数量和来源丢失。现有住宅/商业页面边界、每日面积公式和推荐排序均不作为保留条件。

技术上可行的判断适用于这个明确范围。它不包含“全欧洲自动高精三维覆盖”“设备在任意现场都可用”或“整个工程已合规”的未验证承诺。相关能力应建设和补证，按通过的能力发布；不以删去有价值任务的方式掩盖缺口。

## 1. 产品关系与任务

- 对外保留一个方案设计工具，当前称 **Solution Configurator / Lösungskonfigurator**。**Roof planning / Dachplanung** 是其中的屋顶工作区和重点展示能力。首页可直接引导到这个工作区，进入后仍是同一应用与项目；具体页面文案由原型及英德文案评审验证。
- 用户可以先规划屋顶，也可以输入已知PV容量或既有设备，直接配置系统。屋顶不再受“先填写住宅年耗”的流程限制。
- 屋顶结果至少包含可编辑的屋面、组件排布、片数和kWp，以及输入、来源、假设和待确认内容。当地气象与所需参数可用时，提供与实际阵列一致的发电结果。
- 同一项目按需补充负荷、既有设备、目标与系统约束，并比较候选。住宅/工商业是项目背景；安装商/EPC/经销商是使用者身份。输入与方法按真实需求变化，不用客户身份或项目标签锁住屋顶、储能或其他工作区。
- 储能独立、已有PV改造、无需储能的PV等合理项目不被流程强迫成同一种方案。仅有年耗时可以提供明确范围内的初筛；不能输出伪装成时序仿真的自用/削峰数字。

## 2. 范围包含什么

| 能力 | 纳入本轮重构目标的内容 | 发布需要的证明 |
| --- | --- | --- |
| 屋顶与阵列 | 多栋、多坡、内孔、障碍/禁布区、通道、实际或明确标记的参考组件；平屋顶屋面与组件姿态分开；南向和东西向布局 | 几何、组件边界、数量、kWp一致；安装参数来源清楚；实际尺寸样本核对 |
| 发电规划 | 逐阵列、位置/气象与模型版本、损失及遮挡范围；月/年与所需时序 | 与独立参考/人工可解场景核对，粒度及适用范围明确 |
| 住宅与商业自用 | 同一发电/负荷/设备能流；总负荷与净购电边界；既有PV/新增PV | 能量守恒、自给/自用归属正确；负荷形状与当地发电影响结果 |
| 商业削峰 | 连续SOC、充放电功率、效率、补能限制、目标功率、初末边界 | 跨午夜/多日/无法补能等场景真实可行；不满足时输出具体时段与原因 |
| 备电 | 关键负荷与时长/时序，能量及持续/峰值输出，相、隔离/切换和所需附件 | 实际组合能完成所求任务；缺少事实的项不能显示已通过 |
| 系统选择 | 有来源的具体设备配置、组串、堆叠、端口、并联、配件及国家依据；先验证再比较 | 数量/型号改变重新核验；完整BOM；可交付能力与任务一致 |
| 项目交接 | 编辑/恢复、报告/PDF、Solution draft、询盘预览、账户及Genie | 同一输入和计算版本，各消费者有实际读回证据 |

上述是需要建成并验证的范围，不是对现状的功能声明。静力、风雪载荷、屋面承载、完整支架工程或施工审批若需在产品中给结论，必须有相应模型、原始依据和验收；未纳入验证的部分在成果中逐项列明，不能用于证明可施工。会直接影响布局和发电的安装姿态、间距、障碍及遮挡已经在表内，不能随施工工程一起省略。

## 3. 欧洲覆盖怎样定义

**全欧洲是产品目标，包含英国、瑞士、挪威等非欧盟欧洲市场。** 实现规格须列明确国家清单和逐国能力验收，不能将“只支持德国”作为新模型的默认结构。采用统一地点、时区、单位及尺寸/图纸规划路径；影像和自动模型以数据适配增强。发布能力按国家/地区、来源和日期分别列出，至少区分：

1. 可建立地点与项目；可用实测尺寸或校准图纸建立屋面。
2. 可合法显示且元数据明确的影像。
3. 可获取并验证真实屋面；建筑足迹或LoD1平顶不冒充逐坡屋面。
4. 可用的当地气象与该场景计算方法。
5. 所选设备组合及当地适用条件已核实到哪层。

无自动屋面时仍可走人工路径；缺国家设备依据时仍可保留已成立的布局/发电，但设备结论列为待核。国家与EN/DE界面语言分别验证。国家规则、设备地域放行、气象和负荷适用性由项目地点确定；界面语言不改变项目国家。不能由一个德国阈值推出欧洲适用。完整自动三维覆盖和逐国工程放行按证据验收；缺项是待建设/补证的覆盖项，不通过免责声明伪装为全欧洲已经完成。

## 4. 结果状态采用可逐项验证的含义

| 结果状态 | 含义 | 允许的下一步 |
| --- | --- | --- |
| 可编辑草稿 | 输入或确认尚不完整，计算未完成 | 保存项目、继续补充；不能将未算数字导出为已计算方案 |
| 已计算的局部成果 | 某项布局/发电/能流在明确输入与适用域内完成，其他项仍缺失 | 查看和导出该成果及限制，继续系统任务或带待核项询盘 |
| 已验证可行的候选 | 声称完成的任务及相关硬约束均通过，数据、方法和方案版本可复算 | 比较候选、生成对应报告与完整商品清单；影响本项任务或硬约束的国家/现场依据缺失时仍属“需要补证”，只有不影响该结论的独立施工/审批事项可继续列为待核 |
| 需要补证或无法完成任务 | 关键事实缺失，或现有配置无法满足输入目标 | 给出精确缺项/不可行时段；允许保留成果、修改目标/设备或询盘 |
| 已过期结果 | 输入、方法或设备版本已变化 | 查看历史依据；重算产生新版本，不能当作新输入的结果保存/交接 |

“配对已放行”“选型可行”“当地审批通过”是不同事实，禁止合成一个笼统通过标记。不能用“未知”静默剔除全部工作：已经成立的结果保留，未成立的结论不宣称。

## 5. 选型方法的确定方向

采用 **客户任务 → 数据与计量边界 → 物理/设备可行性 → 同一模型比较候选 → 带依据的结果**。

初始技术路径是对有证据的离散设备配置生成候选，校验电气、数量、兼容和完整度，以连续能流验证任务，再依据明确目标比较。阶段性的无损下限/容量上限可用于解释与剪枝，不能直接当最终推荐。是否需要专用优化器与如何剪枝，留到真实候选规模和性能测量后确定。

明确停止沿用以下逻辑作为完整选型的证明：

- 屋顶确定组件后，在组串层隐式增加数量。
- 在独立HTW参考表和当地发电之间拼接项目自给/自用率；简单钳制百分比也不能替代同源能流。
- 每日超峰面积代替连续SOC，或把午夜当作免费补能点。
- 以电池kWh和逆变器铭牌kW两项达标，代替实际组合可交付能力。
- 用备电容量预留代替备电输出/切换能力验证。
- 配件缺失仍给完整BOM，或增减设备后不再验证放行条件。
- 把默认最大的电池或AC最接近PV当成未经说明的“最佳方案”。

输出比较指标由客户任务决定，不输出回本期。已明确任务与适用范围、完成相关可行性验证，但尚无全局最优性证明时，使用“可行候选/比较结果”。缺少目标、适用范围或必要验证依据时标为需要补证，不能宣称可行或全局最优。

## 6. 用户本轮明确的产品关系

已确认采用一个工具，重点展示屋顶能力，目标面向全欧洲；客户身份不作为工具分叉条件。完整的[统一产品决定](PRODUCT-STRUCTURE.md)列出入口、工作区和后续原型验收。此确认只针对上述关系与目标，不代表用户批准此前原型、最终页面文案、算法、源码复用范围或工程精度。

## 7. 同轮修复工具对全站的影响

用户本轮进一步要求：重做工具只是前半部分；后半部分必须核查并修复对站点其他部分造成的影响。采用[全站影响与同步修复合同](SITE-IMPACT.md)，将入口/内容/旧链接、产品数据、Genie、账户保存、报告、草稿、询盘/团队/Proforma、语言/SEO/共享呈现、统计同意、部署和数据迁移一起纳入。

当前研究将依赖与修复合同核实到真实消费者。正式实现必须同轮修复这些失配并验证完整用户路径；工具本身完成、接口返回成功或CI通过都不能单独结案。不用此范围扩大为无关网站改版，保留原有直接商品询盘和当前已合入的业务接纳/通知/保护能力。

## 8. 当前可以关闭什么，仍需验证什么

三个研究问题已回答：现状有什么问题、选型链能否直接信任、成熟路径及欧洲依赖是什么。它们可以以证据与边界收口，不需要等工具重做完成。

本范围决策由Codex承担。原型的操作质量、生产算法性能、全SKU关键能力及国家依据、现场精度、实际控制器和成本仍须实际取证。本轮已补充原件/方法/规则的代表性深入研究，确定[整体重设计](ARCHITECTURE.md)，并跑通有限架构实验；它们没有替代这些生产验收。后续不会因为人员更换而降低这些门槛，也不会把“用户委托负责”写成“用户已逐项批准全部设计”。
