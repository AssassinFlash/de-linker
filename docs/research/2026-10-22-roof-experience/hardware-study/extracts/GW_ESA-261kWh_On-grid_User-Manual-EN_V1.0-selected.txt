2 Grid-Connected Solution Introduction
In grid-connected scenarios, three parallel operation solutions are supported:
master-slave parallel operation / parallel operation via SEC3000C / parallel operation
via third-party EMS.

• Master-slave parallel operation: ESA261 energy storage system
• Parallel operation via SEC3000C: ESA261 energy storage system + (grid-connected
inverter) + SEC3000C
• Parallel operation via third-party EMS: ESA261 energy storage system + (grid-
connected inverter) + third-party EMS

NOTICE

At the grid connection point, current transformers (CTs) and electricity meters need
to be configured to implement the Power Limit function. Please select a suitable
solution based on actual site conditions:

• If on-site power outage operations are permitted, a primary CT can be installed
at the grid connection point and connected to the GM330 smart meter.
• If on-site power outage operations are not permitted, a secondary CT should be
installed on the existing primary CT and connected to the DTSD1352 secondary
meter.



2.1 Master-Slave Parallel Operation
The ESA261 energy storage system supports master-slave parallel operation. During
master-slave parallel operation, the system does not support connection to PV
inverters, and supports parallel operation of up to 8 energy storage systems. Master-
slave parallel operation is supported only in China.

SEC3000C is equipped with 4 RS485 communication interfaces, one of which is
already used to connect the built-in GM330 meter, and each of the remaining
interfaces can support up to 20 grid-tied inverters in parallel. If the built-in GM330
meter is used directly, or the built-in meter is replaced with an Acrel meter, then up
to 60 grid-tied inverters can be connected in parallel. For details, please contact
after-sales for support.
