## Strict Standards to Ensure Privacy and Information Security



Privacy Policy

Global User Data Protection

We are committed to safeguarding the privacy and security of our users worldwide and have strict, regulation-compliant requirements for the collection, use, and retention of global user data.



Security

Security White Paper

Tencent RTC prioritizes data and user privacy security as the primary security principle.

The Security White Paper provides a detailed introduction to the security construction and compliance audit of Tencent Cloud's real-time audio and video PaaS services.



Information Security

Notes on Information Security

Communications between users and the Tencent RTC server are protected by protocols such as Tencent Cloud's private transfer protocol, Transport Layer Security (TLS), and Web Socket Secure (WSS).

Tencent RTC provides global service through a distributed IDC network with isolation-based protection, ensuring service stability and availability even under DoS attacks, and is equipped with robust DDoS mitigation measures to manage and control security risks effectively.

Tencent RTC has clear and strict requirements for data classification, storage, access authorization, and control to ensure the security of your information.
