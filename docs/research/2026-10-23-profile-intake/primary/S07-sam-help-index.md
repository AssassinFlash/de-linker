# SAM Help[#](https://natlabrockies.github.io/SAM/doc/index.html#sam-help "Link to this heading")

This is the user documentation for the System Advisor Model™ (SAM™) developed by the National Laboratory of the Rockies (NLR).

Important

To display SAM Help correctly in the Safari web browser on a Mac, go to Settings, Advanced Settings, and enable **Show features for web developers**. Developer mode is required in Safari to load CSS and Javascript from local files.

See [https://sam.nlr.gov](https://sam.nlr.gov/) for general information about SAM and links to technical references for SAM’s performance and financial models

Go to [https://sam.nlr.gov/forum](https://sam.nlr.gov/forum) to ask questions and get help from the SAM user community and SAM developers.

See [https://sam.nlr.gov/releasenotes](https://sam.nlr.gov/releasenotes) for version information.

Download SAM for Windows, Mac, and Linux at [https://sam.nlr.gov/download](https://sam.nlr.gov/download). You can also find links to legacy versions of SAM there.

SAM’s source code is available at [NatLabRockies/SAM](https://github.com/NatLabRockies/SAM).

Software developer tools are available at [https://sam.nlr.gov/sdk](https://sam.nlr.gov/sdk), and the PySAM Python package is available at [https://pysam.readthedocs.io](https://pysam.readthedocs.io/).
