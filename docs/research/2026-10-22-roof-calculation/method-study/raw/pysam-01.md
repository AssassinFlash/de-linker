# Installing PySAM — NLR-PySAM 8.0.0 documentation

PySAM for Python 3.8 to 3.14 is available as nlr-pysam to distinguish it from the completely unrelated pysam package for genomic data sets.

Note

PySAM 8.0.0 and newer versions are available as nlr-pysam. Older versions are available as nrel-pysam.

## PyPI[](https://nrel-pysam.readthedocs.io/en/main/installation.html#pypi "Link to this heading")

pip install nlr-pysam

## Anaconda[](https://nrel-pysam.readthedocs.io/en/main/installation.html#anaconda "Link to this heading")

conda install nrel::nrel-pysam

Note

When Anaconda is updated, use conda install nlr::nlr-pysam.
