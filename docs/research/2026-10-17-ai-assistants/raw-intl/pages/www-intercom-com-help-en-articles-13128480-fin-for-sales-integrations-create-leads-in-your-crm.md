[Fin for Sales](https://intercom.help/intercom/en/articles/13927072-fin-sales-agent-explained) can qualify visitors and automatically push their information directly into your CRM. By connecting your CRM via Data connectors, Fin can create new lead records in real-time, eliminating manual data entry for your sales team.

Here is how to set up Fin for Sales to automatically create leads in your CRM.

**Tip:** If you're using Salesforce, Fin for Sales can connect directly to your Salesforce account and build a working data connector for you in minutes, no API knowledge, code, or manual field mapping required. Learn more in our guide to [Connect Salesforce to Fin for Sales](https://www.intercom.com/help/en/articles/15703879-connect-salesforce-to-fin-for-sales).

* * *

# Step 1: Authenticate your CRM

We offer streamlined, pre-configured authentication flows for popular CRMs so you can connect them in seconds.

1.  Go to [Settings > Integrations > Authentication](https://app.intercom.com/a/apps/_/settings/app-settings/authentication) and click **Add token**.
    
2.  Select your CRM from the dropdown list of pre-configured providers. You can choose **Salesforce**, **HubSpot**, or **Attio**.
    
3.  You will be redirected to the provider's authorization page. Review the requested permissions and click **Confirm** (or Allow) to authorize the connection.
    

<signed-url-removed>

**Tip:** Your access token is automatically generated and added to your workspace. Learn more more about [Data connector authentication](https://www.intercom.com/help/en/articles/6615543-setting-up-data-connectors-authentication).

* * *

# Step 2: Set up the Lead Creation Data connector

Now that your CRM is authenticated, you can create the Data connector that Fin will use to send lead data.

1.  Go to [Settings > Integrations > Data connectors](https://app.intercom.com/a/apps/_/settings/app-settings/data-connectors) and click **New > Create from scratch**.
    
2.  Give your connector a clear name (e.g., "Create Attio Record" or "Create Salesforce Lead").
    
3.  Under "HTTP Headers" in the **API** tab, select the token you just created from the **Authentication token** dropdown.
    
4.  Configure your POST request to your CRM's lead creation endpoint, and define the data you want Fin to collect (like Name, Email, and Company) in the request body.
    

## Choosing data inputs

Specify if any data should be collected before this data connector is run. Inputs can come from conversation history, previous actions, or by asking the customer. When adding a data input, you'll set a Data source for it. This controls where the value comes from. There are three options:

*   **Select data attribute**: pulls a value from an existing attribute in Intercom. This includes standard People and Company attributes (for example, First name, Last name, Company name, Company ID) as well as any custom attributes you've already set up, including those configured in your [Fin for Sales playbook qualification flow](https://www.intercom.com/help/en/articles/13927077-how-to-train-fin-for-sales). Use this whenever the data you need is already stored on the contact or company record.
    
*   **Let Fin collect**: Fin decides whether it needs to ask the customer for this value during the conversation. Only use this for fields that aren't available as an existing data attribute and that Fin genuinely needs to gather in real time.
    
*   **Custom value**: lets you enter a hardcoded value. Use this for fixed fields that don't change between leads, such as a record type or source tag.
    

<signed-url-removed>

**Tip:** The most common mistake is creating new "Let Fin collect" attributes for data that Fin already gathers during qualification. Before adding any new attributes, check your playbook qualification fields first — those are already available to reference in the connector's request body.

See the examples below for more details. [Read more about Data connectors](https://www.intercom.com/help/en/articles/6298285-using-data-connectors-for-automation).

### Example: Create Attio Object

Below is an example Data connector setup for creating People objects in Attio. Read more about [Attio’s Standard Objects](https://attio.com/help/reference/managing-your-data/objects/manage-standard-objects).

The request details are:

*   **Method:** POST
    
*   **HTTPS URL:** [https://api.attio.com/v2/objects/people/records](https://api.attio.com/v2/objects/people/records)
    
*   **HTTP Headers:**
    
    *   **Authentication Token:** Select the token that was created when authenticating with Attio
        
    *   **Content-Type:** application/json
        
    
*   **Request Body Format:** JSON
    
*   **Request Body:** Read more about Attio’s API request format [here](https://docs.attio.com/rest-api/endpoint-reference/people/create-a-person-record?playground=open).
    

<signed-url-removed>

### Example: Create Salesforce Lead

The recommended approach for Salesforce is to use a PATCH upsert request. This creates a new lead if one doesn't exist, or updates an existing record if it does which prevents duplicate leads. Read more about [upserting records in Salesforce](https://developer.salesforce.com/docs/atlas.en-us.api_rest.meta/api_rest/dome_upsert.htm).

The request details are:

*   **Method:** PATCH
    
*   **HTTPS URL:** [https://MyDomainName.my.salesforce.com/services/data/v66.0/sobjects/Lead/Email/{{email}}](https://mydomainname.my.salesforce.com/services/data/v66.0/sobjects/Lead/Email/)
    
*   **HTTP Headers:**
    
    *   **Authentication Token:** Select the token that is created from authenticating with Salesforce
        
    *   **Content-Type:** application/json
        
    
*   **Request Body Format:** JSON
    
*   **Request Body:** Read more about Salesforce’s API request format [here](https://developer.salesforce.com/docs/atlas.en-us.object_reference.meta/object_reference/sforce_api_objects_lead.htm).
    

<signed-url-removed>

**Note:** The PATCH upsert above requires Email to be configured as a unique External ID field in your Salesforce org. If Email (or another field like Phone) isn't set as a unique External ID, use a POST request to `https://MyDomainName.my.salesforce.com/services/data/v66.0/sobjects/Lead` instead. Note that POST always creates a new record, so you may need additional logic to prevent duplicate leads.

# Step 3: Add the action to Fin

Once your Data connector is built and tested, you can add it to your Fin for Sales playbook so it automatically triggers when a lead is qualified:

1.  Go to [Fin AI Agent > Sales > Train > Playbook](https://app.intercom.com/a/apps/_/automation/fin-ai-agent/sales/playbook).
    
2.  Scroll down to the **Outcomes** section.
    
3.  Click on the outcome where you want the CRM lead to be created (e.g., click on **Sales**).
    
    <signed-url-removed>
    
4.  In the Sales outcome configuration panel, scroll down to the **Actions** section.
    
5.  Under "Take action", find the "Follow-up workflow" and click the **Edit workflow** button.
    
    <signed-url-removed>
    
6.  In the visual workflow builder, click the action step and choose **Select data connector**.
    
7.  Select the Data connector you just created (e.g., "Create Attio Person" or "Create Salesforce Lead") from the dropdown menu.
    
    <signed-url-removed>
    
8.  Review the data points the connector will use (e.g., Email, First name) and define what should happen if the data connection fails or completes.
    
9.  Click **Save** in the top right corner of the workflow builder, then click **Save** on the outcome panel.

# Verify and troubleshoot your data connector

Once your connector is live, you can check it's working correctly by viewing conversation events in the Inbox. Go to a conversation where Fin ran and select **Show conversation events**. You'll see whether the data connector was triggered and whether it succeeded or failed.

For more detailed guidance on verifying data connector health and diagnosing issues, see:
