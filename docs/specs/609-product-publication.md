# 统一产品与资料发布

依据：[确定以 WooCommerce 为唯一权威的产品与资料发布规则](https://github.com/AssassinFlash/de-linker/issues/609) 的业主确认与 resolution。实现地图：[EcoFlow 停止公开展示与技术资料下架](https://github.com/AssassinFlash/de-linker/issues/607)。本文件记录目标规则与验收要求，不代表实现或生产验收已经完成。

## 唯一维护入口

产品事实、发布状态、资料关联和资料的公开决定在 WooCommerce 的产品与资料入口维护。业主只操作这一个入口，各工具自动获得更新，不另维护品牌名单、手工同步清单或独立商品库。

产品发布与库存状态各有含义，库存继续沿用 Woo 原有权威。屋顶、用电、辐照和兼容依据仍是工程输入；这些输入不能自行扩大产品候选或取得已撤资料的公开许可。

知识索引、工程 feed、缓存及解析结果是可重建的派生数据。它们可以留存内容用于准备与内部归档，客户当前可用范围始终由 Woo 决定。解析结果、内容 SHA、旧 URL 或曾经通过的结果均不授予发布权。

## 领域语言

- **已发布产品**：Woo 当前允许客户读取和使用的产品；语言镜像不能绕过事实源的撤下状态。
- **公开资料关联**：一份托管资料为一款当前已发布产品提供依据的有效关联。同内容文件与不同 URL 可以复用解析，公开许可分别判断。
- **历史快照**：客户当时的方案、询盘或报告记录，保留当时的产品名称、数量与结果；读取历史不隐式重新选型，也不向草稿商品补取当前事实。
- **工具准备状态**：当前产品与资料版本是否已有足够、已验证的解析和工程依据；它不改变 Woo 的发布状态。

## 发布与撤下

业主 2026-10-23 再次确认：本轮“下架”不授予删除产品、技术资料原件或已确认客户历史的权限。产品转为 Woo 草稿，保留记录、SKU、内容和数据；技术资料保留媒体记录与原文件，撤销其公开使用权限，媒体附件不必具有名为“草稿”的状态。恢复发布使用保留对象，不能要求重新建产品或重新上传原件。

新上架产品可以先在网站展示。所需资料与工程数据准备完整后，相关工具自动启用。准备失败要可见、可重试，构建机离线时保留待办；不要求业主手动触发同步。

下架产品、撤下资料或移除最后一个有效公开关联后，后续客户读取、知识检索、引用、推荐、计算、换型、保存、加入 Lösungsentwurf、生成新报告与下载必须立即按当前许可拒绝失效对象。撤权不等待异步准备、定时任务或索引重建完成。

产品、资料关联和附件的不同正常写入口都遵守同一规则，包括后台、WP-CLI、REST、原生产品保存、元数据与附件变更。准备任务只可激活其对应的当前版本，旧任务晚到不恢复已撤权限。

请求使用的全部候选与依据都须有效；仅检查最终选中产品不足以防止失效候选影响排序。输出和下一步操作重新校验，在计算中发生的撤下不得释放旧结果。当前权威不可读时明确停止受影响动作。

## 共用资料与原文件

原版 PDF 同时包含上架 A 与下架 B 时，只要仍为 A 提供有效依据，整份 PDF 可以保持公开。工具只使用 A 适用内容，不将 B 作为当前产品回答、推荐或选型；厂商原件保留完整。

没有任何有效上架关联，或资料被主动撤下时，停止公开检索及下载。原 URL、同内容别名和已缓存引用均在范围内；修改媒体条目状态或只隐藏下载按钮不构成完成。

下载许可绑定产品与资料关联。相同内容 SHA 不将技术手册的公开权授予私有询盘、报告、客户上传文件或其他产品；也不将共享 A 的许可用于补出 B 的当前事实。

同 URL 替换内容必须产生新的资料版本；旧解析和引用不继续冒充当前文件。原件保留，撤下可恢复。

### 原版 PDF 的按请求校验（2026-10-26 性能增量）

原 URL 下载不需要构造所有产品的工程 manifest。`Publication::allows_document()`
每次重新刷新原生运行期缓存，读取相同顺序的当前产品候选及有效 Woo 资料关联，
只解析与所请求 URL 有关的主文件和别名。URL 路径匹配仅缩小候选，不能授权：
相关文件仍经过原有托管路径、私有目录、可读性、媒体公开状态与实际 SHA-256 校验。
主文件、别名和请求时文件对象的字节必须一致；同 SHA 不给无关联 URL 授权。

读取保持原 manifest 的第一条有效主文件记录所定义的别名，不因后来共享产品的
记录而扩大别名集合。主文件或别名撤权、最后关联移除、产品撤回和同 URL 替换仍在
后续读取立即生效。允许/拒绝结果只在这一次读取内共享，不跨请求保留。

`DocumentAccess` 只替换权限调用；410/503、GET/HEAD、Range/416、私有 no-store
响应头和原文件字节流保持。完整 manifest 继续服务工程/FAQ/数值证据，未被精简投影替代。
本地真实 PDF 的旧/候选 HEAD 状态、响应头、长度和字节标识相同，权限装配
3098→102 ms、SQL 609→2；这些是单次本地对照，不冒充线上时延。
最终原生夹具、源码评审、CI、生产发布和原 URL 读回按既有记录收口。

完整 manifest 和资料投影在每次运行期刷新、原生候选查询之后，使用 WordPress
`_prime_post_caches($ids, true, true)` 批量载入同一批文章、元数据与分类关系，
避免逐产品查询。候选顺序、逐语言与事实源发布检查、文件内容及独立读取边界保持；
该原生预取不引入 TTL、不跨读取复用许可，也不替代任何工程或下载校验。

## 历史、旧页面与整套动作

客户本人历史方案、询盘和已生成 PDF 继续按快照查看。当前商品变动不改写这些原件。旧结果重新计算、加入清单、生成新报告或保存为当前方案时，以当前许可整套验证。

任一必需产品或依据失效，就明确要求重新选型。禁止静默替换逆变器或电池、报告内容与屏幕确认结果不一致，以及整套加入时只加入剩余部分却提示完整成功。失败不得留下本次新增的部分清单行。

已经加载到客户设备的内容无法撤回；可控制的是后续读取、重新打开和下一步操作。旧工具屏幕的下一步操作必须重新验证。

## 用户自带资料

对用户主动上传的已下架型号铭牌或手册，只识别型号、说明不在当前供应范围并转团队，不继续该型号技术问答或系统选型。用户上传不能成为继续使用本站已撤资料的旁路。

## 最小实现责任

1. Woo 发布模块统一判断产品、资料关联和当前版本，并由同一维护入口产生持久准备待办。
2. 文件服务对原 URL 与别名执行当前资料许可，保留文件及可逆恢复；避免静态文件短路或未经校验的旧缓存继续下载。
3. Genie 和知识构建、检索、引用、历史恢复及上传处理消费同一当前许可，覆盖全库回退与旧会话，不另建产品权威。
4. 系统选型使用当前许可与已准备产品的交集；计算、旧结果复用、换型、保存、整套加入及 PDF 均受约束。
5. 自动准备负责解析、生成、发布和确认实际在用版本。事件丢失、重启、任务积压与旧任务晚到均不得让撤权失效。

具体接口、作业与文件服务路线由[统一接口研究](https://github.com/AssassinFlash/de-linker/issues/612)和[消费路线研究](https://github.com/AssassinFlash/de-linker/issues/613)核 owning source 后记录；上述业务规则不因技术实现选择改变。

## 验收矩阵

| 情景 | 必须观察到的结果 |
| --- | --- |
| 上架产品转草稿，异步任务未运行 | 各入口的新读取与操作立即排除，不依赖任务完成 |
| A 上架、B 草稿，共用一本 PDF | 原版 PDF 可供 A；当前工具不返回 B 的事实或候选 |
| 删除最后关联或主动撤资料 | 检索、引用、原 URL、别名与下载都撤权 |
| 同 SHA、不同资料权限域 | 只复用内容处理；不互授公开权限 |
| 同 URL 替换 PDF | 资料版本改变；旧解析不能作为新内容依据 |
| 新产品未准备、构建机离线或任务失败 | 保留自动待办与可见状态，不编造依据，不要求人工分别同步 |
| 计算中撤下、命中旧完成结果或旧对话 | 输出前和下一步操作重新验证，拒绝失效结果 |
| 旧逆变器/电池 ID，或从旧结果重新生成报告 | 明确失效，不回退首候选、不静默换方案 |
| 整套加入有一项失效或写入失败 | 整次拒绝/回滚，本次不留下部分新增行 |
| 读取客户自己的历史 | 保留快照，不隐式重算，不补取草稿事实 |
| 下载本人已生成且访问权限有效的历史 PDF | 保留原文件下载，不因相关产品下架封禁，不重新生成或补当前事实 |
| 上传已下架型号资料 | 只识别与转团队，不能继续技术问答或选型 |
| 旧准备任务晚到、丢失事件、进程重启 | 撤权保持；自动对账恢复待办，只激活当前版本 |
| 英德异步镜像尚未追平 | 镜像不增加源产品已撤的客户权限 |
| 实际部署与源文件版本 | 核实际进程、在用索引/feed、监听与站点，不能只核磁盘链接 |

实现按改动层运行真实夹具，完成全量 Spec/Standards 双评审；客户可见状态用 EN/DE、390/1440 实走并留证。第一阶段 EcoFlow 的 68 条草稿、0 条发布和 49 条资料路径 410 是保留基线；替换临时拦截前必须逐项证明新门对等承载。测试邮件沿用 tester 单地址纪律，模型通道不变。
