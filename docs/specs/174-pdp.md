# 174 · PDP 重做（吸附结构修复 + 下半部分新设计语言）

单页范围：产品页（`/product/<slug>/` 与 `/de/produkt/<slug>/`）。上半 = 面包屑 + 画廊 + 简介 + 询盘操作区，
吸附仅限上半；下半 = 卖点/特性、技术数据、Project fit、Documents、FAQ、兼容配对，全宽容器逐一以发丝线分隔。
**验收基准 = 本票验收过的原型变体 A**（`docs/design/2026-10-15-pdp-prototype/index.html?variant=a`，业主裁定
2026-10-15）；复刻像素门（旧 A3 项）对 PDP 作废，见文末变更台账。

## 是什么

- **一条容器规则**：`--pdp-container: 1360px` + `padding-inline: clamp(20px, 4vw, 40px)`（`#tv-storefront-pdp .sf-container`）。
  页面任何区块都用它；旧的 40/16/32px 四套内缩与 `calc(100% - 80px)`/`calc(100% - 32px)` 不再存在。
- **上半**（`#tv-storefront-pdp .pdp-layout`）：`grid-template-areas: "gallery rail" "intro rail"`。
  画廊（左）、简介（左下）、询盘操作区（右，`grid-area: rail`，`align-self: stretch` 填满两行）。
  操作区的 sticky 上下文 = 上半个网格本身，**结构上不可能进入下半**；`content content purchase` 跨行吸附已删除。
- **页内导航**（`.pdp-section-nav`）：`position: sticky`，`top: var(--lk-header-h, 80px)`（实测页头高由 JS 写入），
  通栏底色 + 上下发丝线，内层 `.sf-container` 为可横向滚动条；当前区块由 scrollspy 标 `aria-current="true"`。
- **下半**（`.pdp-content > .pdp-block`）：每个区块自带 `.sf-container`，`padding-block: clamp(48px, 7vw, 88px)`，
  区块之间 `border-top: 1px solid`。空区块（无特性图时的特性带）`display: none` 且不参与分隔线。
- **操作区内容与顺序不动**（只改设计）：品牌 → 型号 → 品名 → 货号 → 价格门 → 关键参数（≤4）→ 库存+配送 →
  主操作 → Ask → Compare/Ask Genie/Documents → Plan with… 折叠。文案零改动（EN/DE 均原样）。
- **手机**（≤860px）：结构保留（画廊卡 → 关键参数卡 → 库存 → 次操作 → 工具行 → Plan with…），
  画廊不再用负 margin 撑边；底部操作条 = 悬浮毛玻璃胶囊（左右 inset 12px、`backdrop-filter: blur(20px) saturate(1.6)`、
  半径 999px、安全区下沿、左价格右动作）；Compare 浮动 chip 与 Genie 悬浮球由实测条高让位。

## 通道（谁承担什么）

- **结构只在 LC 模板**：`plugins/linker-commerce/content/livecanvas/single_product.html` 与其德语孪生 `de/single_product.html`。
  短代码与 PHP 一行未改（`includes/` 无 diff）：询盘操作区、画廊、规格、场景、文档、FAQ、配对的输出原样使用。
- **样式只在 WindPress 卷**：`content/windpress/pdp.css` 是 PDP 的唯一所有者；`content/windpress/storefront.css`
  里的 PDP 复刻层整段删除（`grep -c tv-storefront-pdp` = 0）。WindPress 缓存由 `just windpress-compile <instance>` 重建。
- **JS**：`plugins/linker-commerce/assets/pdp-ui.js`（由 `[linker_pdp_gallery_pair]` 原样入队）。
- **锚类校验**：`WindPressCache::ANCHOR_CLASSES` 用 `pdp-intro`、`pdp-section-nav` 取代已死的 `pdp-scene-reel`
  （后者的选择器只活在已删的复刻层里，现无任何输出使用它）。

## 验收条目

1. 1440 与 390、EN 与 DE：`.pdp-layout` 内含 `.pdp-gallery`/`.pdp-purchase`/`.pdp-intro`；`.pdp-section-nav`、`.pdp-content`
   及其全部 `.pdp-block` 在它之外。
2. 滚动遍历任意位置：操作区不遮任何内容（操作区底 ≤ 首个下半区块顶；下半区块互不覆盖）；390 无横向溢出（`scrollWidth ≤ innerWidth`）。
3. 桌面：`.pdp-buy-inner` 为 `position: sticky`，吸住时 `top` = 实测页头高 + 16px，底 ≤ 视口底；滚动到下半后随上半离开，不再出现。
4. 页内导航吸在实测页头线下（`top` = `--lk-header-h`），锚点落点 ≥ 页头 + 导航高；scrollspy 在页底标最后一个区块。
5. 390：底部操作条为毛玻璃胶囊（`display:flex`、`backdrop-filter: blur(20px) saturate(1.6)`、左右 12px inset、安全区）；
   页面底部留白 ≥ 条高 + 52px；Compare chip 与 Genie 悬浮球在条上方 ≥ 8px。
6. 画廊行为不变：缩略图切换主图、方向键、≤860 横扫切换、点主图开灯箱、背板/Esc 关闭、焦点归还。
7. 规格 deck：点某 tab 只切本 deck 的面板，下方 Project deck（隐藏 tab 条、全面板）不受影响。
8. 文案零改动：操作区（含品牌/型号/品名/货号/价格门/参数/库存/两个操作/三工具/Plan with…）与区块标题 EN/DE 逐字未变；
   禁词零（`catalogue|Katalog|basket|cart|Warenkorb|article` 不出现在模板与新增文案里）。
9. 空区块不出现：无带图特性卡的产品，特性带 `display:none`（页面上不多出一条分隔线、不留空段）。

## 已知偏差（记录在案，非缺陷）

- **库存圆点颜色**：短代码恒输出 `<span class="pdp-dot is-wait">`（PHP 只做数据装配，本票禁改），故圆点无法按状态着色；
  照原型 A 取 accent 绿。若日后 PHP 按状态输出类名，pdp.css 需恢复 `.pdp-dot.is-wait` 的 warn 色规则。
- **导航条目**：原型条有 Overview / Technical data / Project fit / Documents / FAQ 五项；实现沿用模板既有文案的
  Description / Technical data / Applications / Documents（原型新增的 FAQ 条会引入新文案串，按文案纪律不开新串；
  FAQ 区块本身仍在页内）。
- **FAQ 侧图**：原型的 FAQ 左图右栏（`.faq-side`）无数据来源（FAQ 短代码只输出问答行），实现为满宽手风琴。
- **`data-linker-assistant-open="nameplate"`**：pdp-ui.js 仍派发 `lia:open`，该事件在当前 Genie 侧无监听
  （Genie 监听 `linker-genie-open`/`linker-genie-ask`），铭牌入口今日无行为；修它需要 Genie 侧的路由决定，不在本票范围。
