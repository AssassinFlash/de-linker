# 客户表单与原生验证

2026-11-21 业主裁定。客户是否需要 Turnstile 由服务端身份和当前提交的动作决定。匿名询盘、普通联系、Genie 转询盘或联系、注册使用官方组件。已登录客户沿用 WordPress 会话。商品草稿、配置器、报告、普通 Genie 操作、登录、找回密码和评论按各自原生流程操作。

匿名表单随原请求发送 `cf-turnstile-response`。提交处理器核实 Siteverify 成功、当前站点域名及该入口的 action，然后才执行新写入。表单原位刷新过期验证。网络故障或拒绝时保留客户填写的业务资料、选择及草稿，提供重试和销售联系地址。密码、挑战响应和验证码不进入持久化的表单草稿。

商品、数量和私有资料的访问仍由 Woo 会话、nonce 和资料归属决定。一次提交只创建一个原生业务记录。实际存储成功后返回可核实的回执，通知投递按独立状态处理。固定回执不回显客户留言。报价认领、价格审批、外部服务成本和进程资源、邮件传输及隐私删除保持各自的责任边界。

配置器新建与编辑项目、导入资料、计算和生成报告，以及 Genie 新建会话和保存方案，均不按客户或全站每小时、每日的操作次数拒绝请求。重复提交沿用原操作结果。项目归属和历史修订保持有效。

全站已接单数、待审账号数和当日回执数均不构成产品业务上限。工作队列拥堵时继续处理已接受的原单。后台已认定的垃圾及对同一未验证收件人的滥用在产生外部邮件前处理。

验收覆盖英语和正式德语的 1440 与 390 视口。隔离评审使用 Cloudflare 官方测试凭据。生产使用实际域名和密钥，商品草稿与 Woo 回执核对商品与数量。人工验证在客户日常浏览器完成。
