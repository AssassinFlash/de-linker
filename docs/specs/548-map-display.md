# Geographic map display boundary

This is a required seam in the existing map-workbench implementation dossier.
It does not replace map drawing, image calibration, provider/privacy licensing,
Google acquisition or the full unified-workbench delivery.

The map consumes a fresh read-only GeoJSON display projection of the confirmed
metric document. A declared true-north frame and WGS84 geographic anchor are
required; a location label, country or guessed compass cannot establish them.
The accepted complete ENU inverse owns conversion, using the same explicit
zero-height convention as geographic source intake. Roof-relative heights are
neither ground nor measured ellipsoid heights.

Keep every roof opening, source/object/roof identity, module inclusion state,
full module cuboid and obstacle extrusion. Map output cannot mutate the domain
document. World-wrap translation is display-only; a short dateline crossing
must not become a world-width roof. MapLibre's own Mercator latitude boundary
must cause an explicit unsupported display state rather than a silently moved
position. Empty referenced geometry has no fabricated extent. Metric geometry,
plan view, 3D, history, saved revisions and engineering evaluation stay intact.

MapLibre 5.24.0, Terra Draw 1.35.0 and its MapLibre adapter 1.4.1 are pinned to the
combination checked in the implementation dossier. Installed dependencies and
this conversion module alone do not establish a working map UI or provider.
Renderer lifecycle, accessible controls, source/attribution/privacy, complete
gesture transactions, raw-draft recovery, same-project commit/save/reopen and
native EN/DE × desktop/phone acceptance remain part of this active goal.

## Current renderer increment

The third editor view reads the same document and selects the same opaque
objects as plan/3D. View fitting, pan, rotation, zoom, selection, provider toggles
and failures never commit geometry. A view camera is ephemeral per open project;
changes to saved engineering data still use the existing command coordinator.
The map chunk and its explicit retry URL come only from the same native reviewed
build manifest as the entry, with the same strict same-directory validation as
3D. Failure containment is outside either lazy chunk. Original 3D behavior must
remain verified after the shared retry/boundary extraction.

The initial style contains only local project overlays and no external source,
glyph, sprite, tile, geolocation or address-search request. OpenFreeMap's public
street style loads only after the visitor selects the specifically disclosed
Load street map action. This is a transient request for this map view, not a
persistent CookieYes category grant and not analytics consent. Leaving the view
resets it. Hide street map and any native CMP preference update cancel the
external map and restore the local style. A pre-existing statistics grant,
package installation, project location or cached input must not trigger loading.
Privacy policy and full-site consent disclosures remain part of final release;
this increment makes no legal-compliance acceptance claim.

Use the official pinned vendor stylesheet scoped to the workbench, delivered
through the existing WindPress volume, with its BSD notice and source digest.
Site fonts, colours and public controls use existing tokens. Native provider
attribution remains visible, including on a narrow screen; provider errors and
WebGL failure have a truthful retry path. A missing geographic/true-north frame
and unsupported projection remain explicit states with the existing numeric
reference editor available. No country or location label supplies an anchor.

Actual native EN/DE at 1440/390 must prove source placement, holes, actual
provider display/attribution, no-request-before-action, hide/withdrawal, view
selection, same-project save/reopen, and failure/retry behavior. Simulated module
failures and projection arithmetic are narrower evidence. Drawing, calibration,
provider acquisition and the remaining full goal remain required after this
read-only renderer increment.

## Request and local-runtime boundary

The application request scope permits only the explicitly activated
`https://tiles.openfreemap.org` origin from the retained actual style manifest.
It refuses credentials, another origin or port, local-only views and released
owners. The pinned SDK's supported same-origin credentials mode omits credentials on
these cross-origin service requests; referrers are omitted. A style file cannot
expand this grant; worker tile resources use the same MapLibre transform hook.
Release closes this gate before the library cancels its existing work. A map
load failure becomes a terminal retry state rather than an indefinite loading
announcement. Bounded diagnostic attributes omit error bodies, source data and
request paths/queries.

The local isolation MU plugin also needs that exact origin in image/connect
policy. Its prior policy blocked the real external style before any HTTP
response, producing status 0. The versioned local fixture expectation and only
p548's matching runtime copy are updated; native HTTP readback retains the other
policy directives, local mail/outbound isolation and noindex. No other instance
or production policy is edited. Production policy and full-site privacy/readback
remain release gates.
