# Durable pre-send authorization

Owner requirement 2026-10-23; strict runtime base `97ef132f176066c25812c8093a1b5106c443b3fc`. This supersedes the old observation-only notification policy. Current implementation is a checkpoint, not release acceptance.

Native Woo stores complete inquiries before background work. The existing Queue/Action Scheduler/independent minute recovery runs the approved classifier contract; normal creates native full-template team/receipt jobs and exact-purpose permits. Unknown/outage stays pending and uses the existing Outbox retry intervals; exhausted work becomes staff-visible manual work without reminder mail. Customer receipt quotas are reserved only after normal. Existing incident holds are skipped without rewriting their source/job metadata.

Native Woo has no content-classification or purpose-bound sending-permission API. Its ordinary templates/status hooks and JobStore remain authoritative; the narrow custom seam is a connection-owned, uncached native-options CAS journal. Source/staff/policy/route and complete Message plus real attachment digests bind each local permit. Native transactions publish jobs and permission together; caller transactions are not committed by a worker. Outbox rechecks before SMTP/PHP allowance and before PHP fallback. Unattributed legacy jobs stay pending; category/critical/public headers do not grant authority. Native security transactions have exact-message server witnesses created inside their actual producer hooks. No legacy job is re-signed from its subject.

Conversation shares are an independent purpose. Commerce freezes the native full transcript and actual Message into a private job, returning pending rather than sent. A trusted tools hook revalidates the native source independently of browser session. Normal/malicious/unknown use the same private service wire but cannot exchange inquiry/conversation bindings. A missing job is not delivery proof.

Every classification attempt uses the existing absolute ten-second window; provider failures never switch model routes. Each background attempt is durably counted before provider I/O. Retry spacing/count reuse `Outbox::RETRY_DELAYS`, rather than adding an unsupported threshold. The classifier contract is owned separately at `docs/specs/533-pre-send-verdict-contract.md`; observation-v1 results never grant sending permission.

Acceptance requires native positive and negative controls, transaction/storage/late/replay/privacy/staff and old-held checks, related normal-mail baseline, complete static checks, independent Spec/Standards review, exact combined CI and guarded production readback. A development checkpoint and captured local mail are not deployment or inbox evidence. No real mail, production write, model credential or new CSS is part of this worktree.
