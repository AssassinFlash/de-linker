# 公开注册的站级与待处理账号容量

状态：在独立 `codex/569-registration-capacity` 工作树实现中，尚未审查、合并或部署。

依据：[公开注册的站级与待处理账号容量](https://github.com/AssassinFlash/de-linker/issues/569)，以及[全站安全升级地图](https://github.com/AssassinFlash/de-linker/issues/533)。

## 已证实边界

当前生产的 `Operation::begin('registration')` 只有浏览器/账号每日5次、直连每小时100次；它没有独立站级注册额度。原生Ledger、验证次数与短期保留并不限制待处理用户的持久积累。未发现注册攻击已经发生，本票不能计入已确认联系表单攻击规模。

## 初始运营分配

公开注册跨Woo/core入口共享每UTC小时16次、每UTC日32次，保留既有subject与连接限制。它们是本站当前采用的可调整运营分配，非厂商安全阈值或已测真实客户峰值。按每个新注册当前最多两封初始原生通知、之后单独审批通知，32个账号的三封生命周期邮件至多96封；与业务接收96件/日按每件两封的192封保守估算相加为288封，低于内部SMTP标准360封/日的规划量。这不是对客户外发PHP运输的容量保证，发送与持久任务预算仍分别执行，不能以这个估算宣称所有邮件均能立即投递。

额度由原生 `Admission` 在创建用户、VIES和邮件之前原子扣取。轮换浏览器/IP/邮箱/入口不会重开站级窗口；登录、审批、通知送达也不退款已发生的通量。正常登录、重置密码、浏览与询盘不共用这一注册额度。窗口满时保留既有原生错误/重试行为，不能创建新用户或声称注册成功。

## 尚在实现的必要范围

本票还须接通独立持久待处理账号条数与业务字段字节信封、原生创建失败/崩溃/ACK丢失恢复、员工审批处置释放、历史迁移和隐私边界，并接入通知容量的server-only预留。密码不得进入指纹/恢复存储/日志；不删除旧客户，不要求客户MFA。临时站级额度本身不构成完整交付。

预备模块 `RegistrationSlots` 的初始运营分配是128个未处理账号、8MiB业务资料逻辑字节，依据是本票授权选择的资源分配，不是已测客户峰值或磁盘物理上限。模块用一个独立原生option保存创建中断占位的HMAC、时间与预留字节；它不复制邮箱、公司资料或密码，也不按时间释放。已有原生待审/限制客户及带可信公开注册关联的core账号由原生查询计入；客户资料仍归WordPress/Woo所有，不导入第二份。字节读数只包含用户公开业务字段和billing资料，排除密码、重置凭据、session和其他系统存储。历史超额只阻止新接收，不删除旧账号。

源码核实纠正：`Accounts::text` 原先的190字符截取只影响保护指纹，`Registration\\Fields::validate/posted/save` 没有同样的190字符限制。此次改为指纹读取完整原生sanitized字段；不得声称旧站已有该长度上限，也不得按这个错误假设估算邮件容量。原生模板的prospective capture使用未保存的WC_Customer与不含密码的WP_User，由同一个RegistrationInformation字段定义渲染；初步测试已证明长公司名完整、没有账号/VIES/邮件任务副作用。尚未把这些预备API接入公开创建与通知恢复，不能宣称已完成容量保护。

通知预留复用[已验证业务的站级接收与通知积压上限](https://github.com/AssassinFlash/de-linker/issues/568)的 `Mail\Capacity`，不新建第二个邮件队列。团队和客户回执各一个独立的原生notice预留，真实明确关闭/receipt-policy跳过可取消尚未开始的该notice；未知与已进入Outbox的工作不能退款。全部已存业务的通知状态必须真实、可读回。

## 初始红绿证据

独立实例 `r569`（9338，PHP8.3）已加载20261022-1653线上快照：212已发布产品、2756附件、无缺失文件或残留生产地址。只在本机使用原生Ledger/Proof/Operation：第一条合法注册的summary缺少site维度，原生夹具在新增额度前按预期失败，1 test/7 assertions。

原生小时/日窗口与跨廉价身份执行通过之后，仍须双连接、持久占用、完整用户/通知恢复、客户输入/草稿与EN/DE desktop/mobile验证；不得把已存在source或单项绿门冒充最终生产验收。

已接入邮件容量的稳定子提交仅用于本地开发，完整#568尚未审查部署。当前本地注册夹具覆盖站级轮换身份、已有待处理用户/中断占位不随时间释放、原生账号替换精确占位、独立逻辑字节池，以及原生通知预览无写入；公开创建的最终接线与验收仍未完成。
