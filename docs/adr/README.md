# Architecture Decision Records

One decision per file, `NNNN-slug.md`, newest last. A record belongs here when
a choice shapes the tree and could plausibly be revisited (channel choices,
boundaries, trade-offs taken on evidence); day-to-day ticket outcomes stay in
their acceptance records under `docs/acceptance/`. Binding rulings that outrank
ADR reasoning live in `AGENTS.md` (owner rulings) — an ADR may explain, never
override, those.
