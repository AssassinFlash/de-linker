# 系统方案配置器交互原型

打开 [system-configurator.prototype.html](system-configurator.prototype.html) 即可使用，不需要安装依赖。应用内预览配置名为 `system-configurator-prototype`。

这是用于评审操作流程的独立原型，不是生产配置器。产品源码与生产站点未修改。

## 怎么看

顶部“演示场景”可切换六个项目：新住宅、已有光伏规模、已有系统加储能、已选设备、工商业纯储能、大型项目。它是演示工具栏，不是拟议的产品入口菜单。每个场景的修改保留在本次页面会话中。

- 在项目页修改国家、用途和已有设备。欧洲国家与界面语言独立。
- 光伏页选择已知组件资料，或者打开屋顶编辑器。画布可增加屋面、移动角点、拖拽铺组件、加障碍、删除和撤销。尺寸按示例网格显示；平面与斜视示意使用同一组对象。
- 用能页修改典型日程、备电负载/时长、削峰目标。CSV可从本机读取，也可直接使用内置样例；应用前选择列、单位和时间间隔。
- 系统页比较容量配置，调整逆变器规格/数量、电池模块规格/数量，保存一份对照方案再比较。
- 报告与询盘页检查设备清单、加Logo、预览/打印报告、下载CSV、加入草稿并模拟提交。保留的原设备不进入新增采购清单。

“保存当前方案”仅保存本次页面会话中的快照。刷新页面会回到示例；不使用账号、数据库或浏览器永久存储。所有文件读取在浏览器本地完成，模拟询盘不会发送邮件。

## 数据边界

设备是明确标注的示例，不代表Linker当前商品或已放行组合。实际联动包括布局、组件数和功率、设备数量和容量、方案副本、报告及询盘清单。

典型日曲线是演示曲线，按输入年耗的日平均缩放。CSV曲线显示导入的值；能量单位按所选时间间隔换算为平均功率。削峰页计算曲线峰值、超出目标的功率与电量，未模拟电池充放电。备电负载电量为功率乘时长，未计效率和功率限制。

当前项目没有伪造的发电量、自用率或兼容放行。结果页折叠区保留一份注明来源和输入的Sunny Design参考结果，仅用来讨论能源比较的呈现。斜视图是同一布局的示意投影，不是工程级3D。底图是示例平面，不是真实航拍；导入图片为视觉参照，不自动成为测量基准。

正式地图、CAD/3D、工程模拟、跨品牌放行与真实询价接入属于后续产品实施，不因这个交互原型而被宣称已交付。

## 已完成的操作核对

- EN/DE六个场景分别走到报告、草稿与模拟询盘确认；改造场景的原设备不出现在新增采购表。
- 实际鼠标拖动组件、画障碍（组件数24→19）、撤销恢复24、新增第二屋面并铺16块组件；选择器与方向按钮可精调手机上的组件。
- 内置96点曲线及真实File读取路径均已操作。非首列Wh数据按15分钟换算，2500/5000 Wh显示为10/20 kW。
- 修改50 kW备电负载为6小时，示例容量候选反映300 kWh负载电量；纯储能的无新增储能对照方案没有新增采购项。
- 方案快照恢复、规格替换、Logo与图纸本地读取、报告内容及打印内容准备已核对。未自动保存操作系统打印对话框中的PDF文件。
- EN/DE在1440与390宽度实看主要界面；浏览器无控制台错误。图表单序列颜色通过色板检查。

## 文案审阅

主线完成EN初稿、反向检查与DE独立措辞调整，中文供业主评审。

| 初稿方向 | 审阅问题 | 采用措辞 |
|---|---|---|
| Ready to send | 容易把模拟误读为已发送 | Simulate inquiry / Anfrage simulieren；确认页明确未发送 |
| Recommended system | 示例不构成选型放行 | Starting configuration / Ausgangskonfiguration；设备逐项标为示例 |
| Required storage size | 尚未知道容量的客户不能先被要求决定容量 | Required power and capacity already known? / Leistung und Kapazität bereits bekannt?，放在可展开的已知要求区 |

逐条检查可见文字：无借用厂商声誉的营销断言、无虚构时效、无付款或物流承诺；技术信息留在对应输入/结果。操作按钮和字段描述实际动作，保留必要的演示性质说明。
