# 原型：首页 hero 打字之后怎样（#231，地图 #220）

**一次性原型，不进生产。** 问题：hero 未交互时外观不动（业主 2026-10-17）；打字回车、点胶囊、拍照、附件、语音之后，对话怎样原地展开、怎样接上右下角 dock、怎样比旧 Advisor 更好。

## 三个变体（在真实首页上，`/?variant=A|B|C`）

| 变体 | 做法 | 适合 |
|---|---|---|
| **A · 交给右下角 Genie** | 问题直接送进右下角 dock 开聊（旧 Advisor 的行为），dock 顶部标出"Asked from the homepage"，hero 下方短暂提示"Genie is answering in the panel on the right →"，hero 输入框清空 | 改动最小，全站一个对话入口 |
| **B · 就地展开** | hero 的标题、胶囊收起，输入框原地长成对话区（产品卡四列），输入框变成追问框；滚出 hero 时右下角出现"继续对话"胶囊，可转到 dock | 首页就是对话现场，最像"一输入就开聊" |
| **C · 专注模式** | 页面变暗，弹出大对话视图：左侧对话与产品卡，右侧"下一步"（对比、查配对、加入 Lösungsentwurf、开配置器），Esc 返回，返回后右下角留"继续对话"胶囊 | 长时间选型、比较多款产品 |

三个变体共用：脚本回答（**不是真实 Genie**）、产品卡取自本站产品数据（Store API，只读）、拍照/附件走文件选择（回答是脚本示例）、语音是模拟听写（实现用浏览器自带听写）、首条说明"Genie is Linker's AI assistant"。站点自带的右下角圆钮在原型里打开原型 dock。

## 怎么看

1. `just up m4check`（实例已装 `zz-prototype-220.php`，从本工作树加载原型）
2. 打开 `http://127.0.0.1:9033/?variant=A`，底部切换条或 ← → 键换变体
3. 试：输入 `saj` 回车；点三个胶囊；点拍照 / 附件 / 麦克风；B 里往下滚；C 里按 Esc

截图在 `screens/`（1440 与 390）。
