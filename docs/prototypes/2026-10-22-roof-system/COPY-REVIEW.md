# 原型文案：初稿、对抗检查与定稿

2026-10-22。讨论语言中文，客户界面EN/DE独立撰写；内部导览与客户区域在页面中分开。本文件记录Codex逐行审查，不冒称另一位作者或真实用户已批准。

依据：当前项目用词及业主裁定、linker-copywriting Hard Stops 1–9与encyclopedia。新增维度为“工具的入口、操作及成果关系”，不编写物流、授权、服务时效或认证营销。

## 初稿意图

- 主标题说明可先屋顶、也可由已知容量进入；操作描述确认输入、成果及下一步。
- 屋顶卡使用“module layout / module count / PV capacity”；系统卡使用“system / demand / comparison”。
- 报告、草稿、询盘和Genie使用同一项目/结果引用，修改与待核状态清楚展示。

## 对抗检查与采取的修改

1. **预设系统可能被误读为真实推荐。** 定稿命名“Preset system / Vorgegebenes System”，客户区域说明未运行真实选型/能流，状态写“Demo conditions complete / Demobedingungen vollständig”。不写“released system”“optimal”或真实型号。
2. **国家选项容易暗示整国放行。** 定稿依据面板明确没有真实国家放行或固件证书。国家只控制本例项目上下文，不改变虚构的发电数字；原型不提供发电数字。
3. **平面排布可能被当作可施工。** 定稿将场景、图和布局方式称为2D footprint illustration / 2D-Belegungsschema；示例间距明确不是安装规则，未计算支架、倾角、遮挡或电气。
4. **保存/询盘按钮容易构成未发生动作的承诺。** 保存表述限本页内存，报告、Solution draft / Lösungsentwurf与询盘均明确“preview”。没有账号保存、PDF生成或发送成功提示。
5. **旧结果与新输入容易混读。** 定稿同时显示报告输入版本与当前输入版本；过期状态给出具体动作理由，不使用笼统错误或总免责声明替代。
6. **DE不能只是英文字符串漏译。** 手写独立德语句子，按钮、国家、输入、判断、报告、交接和通知均有DE文本；保留单位及示例标识。中文导览为内部说明，不冒称德语客户界面的一部分。
