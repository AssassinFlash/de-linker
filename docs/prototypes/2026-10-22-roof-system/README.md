# 屋顶与系统规划：可操作流程原型

2026-10-22。对应[新手怎样完成屋顶规划并看懂可信结果？](https://github.com/AssassinFlash/de-linker/issues/553)，地图为[屋顶规划与系统选型可信性审查及重构路线](https://github.com/AssassinFlash/de-linker/issues/548)。用户读完架构后表示不理解，明确要求调用`/prototype`展示。

## 本次回答的问题

**屋顶怎样独立完成，再沿用同一个项目进入住宅/工商业系统设计？输入改变、证据不足、来源失败时，成果与交接发生什么变化？**

采用prototype技能的LOGIC分支：一个自包含HTML、纯状态模块、自由操作和分步导览。中文讲解层与客户操作区域分开；客户区域可切换中文讲解、EN及DE。此轮不比较多种视觉方向，不是正式站点设计稿。

## 打开

- 直接用浏览器打开[prototype.html](prototype.html)。脚本/样式/图形均内联，无外部依赖、安装或构建步骤。
- 本次实际展示地址：`http://127.0.0.1:8793/`。内置浏览器只支持HTTP/HTTPS，故使用可选[preview.py](preview.py)提供受限预览：`python3 docs/prototypes/2026-10-22-roof-system/preview.py`。它只绑定回环地址，只返回这一份固定文件，不开放目录、任意文件路径、上传或接口。
- 刷新重置。所有项目/保存/报告/交接均在内存，没有真实账号、数据库、询盘或邮件。

## 可以点什么

| 导览 | 场景与观察 |
| --- | --- |
| 屋顶独立完成 | 进入屋顶、提交并完成模拟任务、查看独立屋顶报告；不需要年耗 |
| 继续工商业系统 | 相同项目/屋顶进入需求、加载合成样例元数据、系统案例比较、草稿和Genie上下文预览 |
| 改输入后怎么办 | 24m改30m后排布变更，旧报告保留原数量；旧结果交接被阻止，重算后交接新版 |
| 资料不足怎么办 | 增加备电目标，任务完成但备电依据待核；阻止“整套齐备”，保留成果及待核询盘预览 |
| 欧洲与来源失败 | 荷兰示例、自动来源失败、手工恢复；项目和尺寸不清空，依据显示未接入内容 |

此外可以编辑尺寸/已知容量并应用、选择国家/住宅或工商业、切换二维排布、点选排除/恢复组件、取消任务、在内存记住/恢复输入、查看历史结果及预览报告/交接。改完尺寸后可先应用，也可在生成结果时应用。无效编辑保留，不变成有效零值。

## 数据与计算的真实范围

- **二维占位是实际可操作的示例逻辑。** 参考矩形2.0×1.1m、460W；示例1m边距、1.2m通道、3×3m禁布区。矩形不相交的网格占位产生数量，`片数×460÷1000`产生kWp。这些常数全部是演示设定，不能作为安装规则。
- 切换东西向/南向只改变平面矩形姿态；没有倾角、3D、支架、行间遮挡、I-V、MPPT或结构计算，不得据此认定真实平屋顶精度。
- 发电、自用、削峰、备电仿真与真实选型没有接入，界面不提供虚构的产量/自给率。系统A/B与“条件齐备/备电待核”为预设案例，不对应真实SKU、厂商或国家放行。
- 用电样例仅有7天/672个15分钟区间的场景元数据和24点示意图，不是已解析672条真实负荷。真实文件导入、时间清洗、图纸校准及地图绘制不由本次原型证明。
- 自动屋面是预设模型；DE/NL/FR是地点上下文示例，没有请求建筑数据库、天气或国家规则服务。地区能力/证书不由选择框推导。
- 报告是HTML预览；没有生成PDF。草稿和询盘只显示将交接的引用/数量/待核项，没有写入Woo或发送任何邮件；Genie没有调用AI。

## 可以得出的结论与待用户反应

演示已把“独立任务、共享项目、固定结果版本及局部成果保留”变成可观察的操作。它揭示了编辑缓冲必须可见且有明确应用动作，也让“任务完成”与“工程条件齐备”分开。
