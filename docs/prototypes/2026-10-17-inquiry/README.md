# 原型：询盘对所有人开放（#246，地图 #220）

**一次性原型，不进生产。** 两个问题：Proforma 请求页对访客长什么样；联系表单的留言和询盘怎样成为"两扇门、一份记录"。

- `screens/1-contact-live.png`：线上联系表单现状；`4-proforma-approved.png`：已批准客户现在看到的 Proforma 请求页（Woo 结账字段很多）；`5-proforma-guest-live.png`：访客现在只看到"请登录"。
- 原型 `/proforma-request/?iq=A|B|C`（产品取自访客真实的 Lösungsentwurf，发送不写数据库）：
  - **A** 访客 · 单卡，联系表单的样子：草稿产品 → 留言（选填）→ 姓名、回复邮箱、公司（选填）→ 同意 → 发送；"不需要账号，一个工作日内回复"；发送后感谢页带"用这个邮箱创建账户"。
  - **B** 访客 · 左表单、右草稿。
  - **C** 已登录：资料已知、折叠成一行（可展开修改），只留留言与发送。
- 后台 `Inquiries (prototype)`：留言与询盘在同一张列表，类型、状态、账户身份一眼可见（示例数据）。

本地运行：`just up m4check`；草稿里先加产品；打开上面地址。后台需 `just login m4check --user 857558227@qq.com`。
