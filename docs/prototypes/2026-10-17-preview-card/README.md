# 原型：Genie 主动预览卡（#249，地图 #220）

**一次性原型，不进生产。** 按 Genie 目标第 4 条（`docs/specs/13-genie.md`）做的预览卡：首页、产品、分类、解决方案页上，访客滚过主内容并停留约 8 秒，右下角出现一张小卡，点名当前页面并给 2–4 条建议；点一条建议就打开站点真实的 Genie 并直接提问。

## 三种样子（`?pc=A|B|C`）

| 变体 | 样子 |
|---|---|
| **A · 提示卡** | Genie 圆钮上方一张小卡：标题点名页面（"Looking at the SAJ H2-10K-T3?"）、一句说明、2–4 条建议按钮、AI 提示 |
| **B · 气泡** | 圆钮左边一行气泡（"Looking at the SAJ H2-10K-T3? Ask Genie"），点开才展开建议——最不打扰 |
| **C · 情境卡** | 更大的卡：产品页带产品图与三行动作；首页是"Genie 能做什么"四宫格（报型号、拍铭牌、上传清单、比较品牌） |

规则（三种共用，都是真的在跑）：滚过主内容（首页是滚过 hero）后停留约 8 秒才出现；每次访问最多一次；对话进行中不出现；点 × 关掉后 30 天不再出现；手机端不出卡，只在 Genie 圆钮上出红色标记。底部条显示当前规则状态（是否已滚过、倒计时、是否已出现 / 已关闭），"现在显示"跳过等待，"重置"清掉记忆。

## 怎么看

1. `just up m4check`（实例已装原型加载器 `zz-prototype-220.php`）；`just serve m4check` 让点建议后的 Genie 真的回答
2. 打开：首页 `http://127.0.0.1:9033/?pc=A`、产品 `/product/saj-h2-10k-t3/?pc=A`、分类 `/product-category/inverters/?pc=A`、解决方案 `/solution/residential-storage/?pc=A`
3. 往下滚、等 8 秒；或点底部"现在显示"。←/→ 换样子。

截图在 `screens/`。实测：滚动前不出现、滚过 3 秒不出现、9 秒出现；关掉并刷新后不再出现；点建议打开真实 Genie 并得到回答。
