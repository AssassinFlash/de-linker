# Commerce vocabulary: the one wordlist the customer-visible copy is held to.
#
# This file is the single authority. docs/specs/11-commerce.md and AGENTS.md §3
# point here instead of carrying their own copies of the list (issue #905): the
# site has one link, product → inquiry (presented as a Proforma), and everything
# after that happens offline (AGENTS.md §1). Copy must not describe a shop.
#
# Format: one term per line. `#` starts a comment. A trailing `*` matches the
# stem as a prefix, so compounds and inflections match too ("Versand*" covers
# Versand, Versandkosten, Versandart). Without `*` the term matches as a whole
# word. Matching ignores case and uses word boundaries, the same semantics as
# the shared German list (plugins/linker-i18n/data/banned-de.json).

# English commerce nouns. Prefixes where the stem is unambiguous in this
# domain; explicit forms where a prefix would collide with unrelated words
# ("cart*" would match carton and cartridge, so the plural is its own line).

checkout*
payment*
shipping*
cart
carts
basket*
catalogue*
article
articles
